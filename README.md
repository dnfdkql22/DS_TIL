시계열 데이텅

- 시간간격으로 배치된 데이터들의 수열

- 해석 : 시계열을 해석하고 이해하는 데 쓰이는 여러 가지 방법을 연구

= 시간정보(날ᄍᆞ, 시간, 주, 월, 분기 등)포함

= 관측순서가 의미를 가짐

 

시계열 데이터와 순차데이터

Sequence Data( 시퀸스 데이터, 순차데이터)

- 시퀀스 데이터란 순서대로 정렬된 데이터의 연속이다.

- 이 데이터 유형은 특정 순서에 ᄄᆞ라 배열된 항목들로 구성되며, 각 항목의 순서는 데이터 해석에 있어 중요한 역할을 한다.

- 시퀀스 데이터는 다양한 분야에서 나타나며, 예를 들어 생물학에서는 DNA서열, 컴퓨터 과학에서는 문자열이나 시간에 따른 이벤트 로그, 금융에서는 시간에 따른 주식가격변동 같은 형태로 나타난다.

시퀀스 데이터 = 순서가 의미가 있는 데이터의 총칭

시계열 대이터 = 시퀀스 데이터 중에서 ‘시간(Time)’축에 따라 기록된 데이터

시계열 데이터 ⊂ 시퀀스 데이터

 

반정형 데이터

= 데이터 내부에 규칙적인 태구나 메타데이터를 포함하여 데이터 구조 정보를 함꼐 제공하는 형태의 데이터

주요특징

- 자체구조화 : 데이터 자체에 스키마 정보(태그, 키 등)가 함꼐 저장, 어떤 데이터인지 스스로 설명

- 유연한 확장성 : 고정된 데이터 필드가 없기 때문에 새로운 데이터 항목의 추가나 구조변경 용이

- 정형 변환 가능 : 내재된 메타 데이터 규칙을 파악하여 테이블 형테(정형 데이터)로 매핑할 수 있음

** 독립변수는 종속변수에 영향을 주며, 종속변수는 독립변수의 영향을 받아 변형된다. **
