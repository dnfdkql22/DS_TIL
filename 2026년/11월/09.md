# 데이터 시각화 (Matplotlib / Seaborn)

## 1. Matplotlib

- 대표적인 데이터 시각화 라이브러리
- 간단한 플롯부터 복잡한 그래프까지 다양한 형태의 시각화 지원

### 1-1. 주요 기능

- **다양한 그래프 생성** : 선 그래프, 막대 그래프, 히스토그램, 산점도 등 다양한 형태의 그래프 생성
- **고급 사용자 정의** : 축, 레이블, 범례, 색상, 스타일 등을 세밀하게 조정 가능
- **다양한 출력 옵션** : 그래프를 이미지 등 다양한 형식으로 저장하거나 웹 애플리케이션에 내장 가능

### 1-2. 활용 효과

- **시각적 이해** : 복잡한 데이터를 시각적으로 표현하여 데이터를 쉽게 이해
- **의사결정 지원** : 데이터의 패턴과 경향을 파악하여 합리적인 의사결정에 도움
- **커뮤니케이션 강화** : 데이터를 직관적으로 전달하여 원활한 정보 공유 가능

## 2. 주요 그래프 종류

### 2-1. 선형 차트 (Line Plot)

- 시간의 흐름에 따른 데이터의 변화를 나타낼 때 효과적인 그래프
- 데이터의 추세와 변화 패턴을 파악하는 데 사용

**예시**
- 분기별 매출 실적
- 월별 방문자 수
- 일별 주가 변화

**주요 기능**

- **Grid 표시** : X축과 Y축의 눈금을 기준으로 격자선을 표시하여 데이터의 값과 위치를 쉽게 파악
- **구간 확대 및 축소** : X축과 Y축의 최솟값 및 최댓값을 설정하여 그래프의 표시 범위 조정
- **데이터 강조** : 특정 데이터에 화살표(Annotation)와 설명 문자를 함께 표시하여 중요한 정보 강조

### 2-2. Subplot (여러 그래프 배치)

- 하나의 화면(Figure)에 여러 개의 그래프(Axes)를 배치하는 기능
- 여러 데이터를 동시에 비교하거나 분석할 때 사용

**주요 구성 요소**

| 구성 요소 | 의미 |
|---|---|
| 행 (Rows) | 화면을 세로 방향으로 나누는 칸의 수 |
| 열 (Columns) | 화면을 가로 방향으로 나누는 칸의 수 |
| 위치 번호 (Index) | 나누어진 칸 중 그래프를 배치할 위치 |

**위치 번호 규칙**

- 번호는 1부터 시작
- 왼쪽 위에서 오른쪽 방향으로 진행한 후 아래쪽 행으로 이동

**예시**

- `plt.subplot(2, 2, 1)` : 2행 2열로 나눈 화면의 첫 번째 위치에 그래프 생성
- `plt.subplot(2, 2, 2)` : 두 번째 위치에 그래프 생성

### 2-3. 막대형 차트 (Bar Chart)

- 항목별 데이터의 크기를 비교할 때 사용하는 그래프
- 범주형 데이터 간의 차이를 직관적으로 파악하는 데 유용

**예시**
- 제품별 매출액 비교
- 부서별 인원수 비교
- 지역별 판매량 비교

### 2-4. 도수분포표 (Frequency Distribution Table)

- 수치 데이터를 여러 개의 구간(계급)으로 나누고, 각 구간에 속하는 데이터의 개수(도수)를 정리한 표

**주요 용어**

- **계급 (Class)** : 데이터를 구분하기 위해 나눈 구간
- **도수 (Frequency)** : 각 구간에 속하는 데이터의 개수
- **계급의 크기** : 각 구간의 너비

**체크포인트**

- 구간이 서로 겹치지 않도록 설정
- 모든 데이터를 빠짐없이 포함하도록 설정
- 전체 도수의 합계 = 전체 데이터 개수

### 2-5. 히스토그램 (Histogram)

- 연속형 데이터를 여러 구간(Bin)으로 나누고, 각 구간에 속하는 데이터의 빈도수를 막대로 표현한 그래프
- 데이터의 전체적인 분포와 형태를 파악하는 데 사용

**주요 구성 요소**

| 구성 요소 | 의미 |
|---|---|
| Bin (빈) | 데이터 범위를 나눈 각각의 구간 |
| 막대 | 각 Bin에 속하는 데이터의 빈도수 표현 |
| X축 | 데이터의 구간 및 범위 |
| Y축 | 각 구간에 속하는 데이터의 빈도수 |

- Bin은 일반적으로 동일한 크기로 설정하지만, 필요에 따라 구간의 크기를 다르게 지정할 수 있음
- 막대의 높이는 해당 구간에 포함된 데이터의 개수를 의미

**사용 목적**

- **데이터 분포 확인** : 데이터가 정규분포를 따르는지, 한쪽으로 치우쳐 있는지 등 분포 형태 확인
- **중심 경향 파악** : 데이터가 어느 구간에 집중되어 있는지 확인하여 평균, 중앙값 등의 위치를 이해하는 데 도움
- **데이터의 변동성 파악** : 데이터가 얼마나 넓게 퍼져 있는지 시각적으로 확인

### 2-6. 산점도 (Scatter Plot)

- 두 변수 간의 관계를 시각적으로 표현하는 그래프
- 각각의 데이터 포인트를 X축과 Y축의 좌표로 표시

**사용 목적**

- 변수 간의 상관관계 파악
- 데이터의 패턴 및 추세 확인
- 변수 간의 양의 상관관계, 음의 상관관계 및 관계가 없는 경우 확인
- 이상치 탐지

## 3. 시각화의 함정

- 시각화의 방식과 방법에 따라 실제 데이터의 의미나 관계가 왜곡될 수 있으므로 주의해야 함

**주의사항**

- 축의 최솟값과 최댓값을 임의로 조정하면 데이터 간 차이가 과장되거나 축소될 수 있음
- 그래프의 크기와 비율에 따라 데이터의 추세가 다르게 보일 수 있음
- 일부 데이터만 선택하면 전체적인 데이터의 특성을 잘못 해석할 수 있음
- 그래프의 제목, 범례, 단위 등을 정확하게 표시해야 함

### 머신러닝에서 X와 Y의 의미

| 구분 | 의미 | 설명 |
|---|---|---|
| X | 독립변수 (Feature) | 결과를 설명하거나 예측하는 데 사용하는 입력 데이터 |
| Y | 종속변수 (Target) | 예측하거나 설명하려는 결과 데이터 |

- **X (Feature)** : 모델이 학습에 사용하는 설명변수
- **Y (Target)** : 모델이 예측하고자 하는 목표변수

※ 기존의 X와 Y 설명은 반대로 작성되어 있어 수정함.

### Grid (격자선)

- 그래프의 X축과 Y축 눈금에 맞춰 가로 및 세로 방향의 격자선을 표시하는 기능
- 데이터 포인트의 위치와 값을 쉽게 파악할 수 있도록 도움

## 4. 원형 차트 (Pie Chart)

- 전체 대비 각 항목의 구성 비율을 확인할 때 유용

**사용 목적**

- 전체에서 특정 항목이 차지하는 비율 확인
- 항목별 구성비 비교
- 데이터의 구성 및 비중 파악

**예시**
- 제품별 매출 구성비
- 부서별 인원 비율
- 시장 점유율

## 5. 사분위수 (Quartile)

### 5-1. 사분위수의 개념

- 데이터를 크기순으로 정렬했을 때, 전체 데이터를 4개의 동일한 비율로 나누는 기준값
- 데이터를 4등분하는 위치에 해당하는 값

| 구분 | 의미 | 누적 비율 |
|---|---|---|
| Q1 (제1사분위수) | 하위 25% 지점 | 25% |
| Q2 (제2사분위수) | 중앙값 (Median) | 50% |
| Q3 (제3사분위수) | 하위 75% 지점 | 75% |

**사분위수를 통해 파악할 수 있는 정보**

- 데이터의 중심 위치
- 데이터의 분포 및 퍼짐 정도
- 이상치 탐지

### 5-2. IQR (Interquartile Range, 사분위 범위)

- 데이터의 중간 50%가 분포하는 범위를 나타내는 지표
- 제3사분위수(Q3)에서 제1사분위수(Q1)를 뺀 값

**계산 공식**

`IQR = Q3 - Q1`

**예시**

```python
import numpy as np

data = np.array([1., 4., 8., 17., 30.])

Q1 = np.percentile(data, 25)
Q3 = np.percentile(data, 75)

IQR = Q3 - Q1

print(Q1)   # 4.0
print(Q3)   # 17.0
print(IQR)  # 13.0
```

### 5-3. IQR을 이용한 이상치 탐지

- IQR을 이용하면 데이터의 정상적인 분포 범위를 벗어난 이상치를 탐지할 수 있음
- 일반적으로 IQR의 1.5배를 기준으로 이상치 판정 범위를 설정

**이상치 판정 공식**

- 하한 (Lower Bound) = Q1 - (1.5 × IQR)
- 상한 (Upper Bound) = Q3 + (1.5 × IQR)

**판정 기준**

| 구분 | 판정 기준 |
|---|---|
| 하한 미만 | 하한보다 작은 값은 하단 이상치 후보 |
| 정상 범위 | 하한 이상, 상한 이하 |
| 상한 초과 | 상한보다 큰 값은 상단 이상치 후보 |

**계산 예시**

- Q1 = 4
- Q3 = 17
- IQR = 17 - 4 = 13
- 1.5 × IQR = 19.5

따라서,

- 하한 = 4 - 19.5 = -15.5
- 상한 = 17 + 19.5 = 36.5

**최종 판정**

- -15.5 미만 : 하단 이상치 후보
- -15.5 ~ 36.5 : 정상 범위
- 36.5 초과 : 상단 이상치 후보

※ IQR 기준을 벗어났다고 해서 반드시 잘못된 데이터라는 의미는 아님. 실제 이상치 여부는 데이터의 특성과 분석 목적을 함께 고려해야 함.

## 6. Seaborn (씨본)

- Matplotlib을 기반으로 만들어진 대표적인 데이터 시각화 라이브러리
- 간단한 코드로 통계적 특성을 반영한 풍부한 시각화 구현 가능
- Pandas DataFrame과의 연동이 편리함

### 6-1. 주요 기능

- **통계 시각화 그래프 제공** : 데이터 분포, 변수 간 관계, 범주별 비교, 상관관계(Heatmap) 등 다양한 그래프 지원
- **Pandas DataFrame 연동** : DataFrame의 컬럼명을 이용하여 간편하게 시각화 가능
- **기본 스타일 및 테마 지원** : 그래프의 색상, 배경, 스타일 등을 간편하게 설정 가능

### 6-2. 활용 효과

- **탐색적 데이터 분석 (EDA)** : 데이터의 분포와 변수 간 관계를 시각적으로 파악
- **가독성 높은 시각화** : 기본적으로 제공되는 스타일과 색상으로 직관적인 그래프 생성
- **분석 효율 향상** : 복잡한 시각화 작업을 간단한 코드로 구현 가능

### 6-3. Hue 옵션

- 데이터의 특정 변수에 따라 그래프의 색상을 구분하는 옵션
- 범주형 데이터의 추가적인 정보를 색상으로 표현하는 데 사용

**주요 기능**

- 데이터 내 그룹이나 카테고리에 따라 서로 다른 색상을 적용
- 특정 변수에 따른 데이터의 패턴을 쉽게 파악
- 여러 그룹의 데이터를 하나의 그래프에서 구분하여 비교 가능

**적용 가능한 그래프**

- 산점도 (Scatter Plot)
- 막대그래프 (Bar Plot)
- 선 그래프 (Line Plot) 등

**예시**

```python
import seaborn as sns

sns.scatterplot(
    data=df,
    x="키",
    y="몸무게",
    hue="성별"
)
```

- X축 : 키
- Y축 : 몸무게
- Hue : 성별에 따라 데이터 포인트의 색상 구분
