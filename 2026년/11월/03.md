# Python 문법 및 데이터 분류

# 1. 데이터의 분류

데이터는 분류하는 관점에 따라 여러 유형으로 구분할 수 있다.

| 관점 | 정의 | 구분 |
|---|---|---|
| 데이터의 구조적 유형 | 데이터가 어떻게 구성되어 있는가? | 정형, 반정형, 비정형 |
| 변수 유형 | 분석할 항목의 값이 무엇을 의미하는가? | 범주형, 수치형 |
| 변수 역할 | 모델링에서 해당 항목을 어떻게 사용하는가? | 설명변수, 입력변수(X), 목표변수(Y) |
| 데이터 타입(자료형) | 프로그램이 값을 어떻게 다루는가? | int, float, str, bool |

## 1-1. 데이터의 구조적 유형

| 유형 | 정의 | 예시 |
|---|---|---|
| 정형 데이터 | 행과 열로 일정한 구조를 갖는 데이터 | Excel, CSV, 데이터베이스 |
| 반정형 데이터 | 일정한 구조를 가지지만 행과 열 형태로 고정되지 않은 데이터 | JSON, XML, HTML |
| 비정형 데이터 | 정해진 구조 없이 다양한 형태로 존재하는 데이터 | 이미지, 동영상, 음성, 문서 |

## 1-2. 변수 유형

| 유형 | 정의 | 예시 |
|---|---|---|
| 범주형(Categorical) | 데이터를 특정 그룹이나 범주로 구분 | 성별, 직업, 지역 |
| 수치형(Numerical) | 숫자로 표현되며 수량이나 크기를 나타냄 | 나이, 키, 몸무게, 매출액 |

## 1-3. 변수 역할

| 유형 | 정의 | 예시 |
|---|---|---|
| 설명변수(Explanatory Variable) | 결과에 영향을 주거나 결과를 설명하는 변수 | 광고비, 공부시간 |
| 입력변수(Input Variable, X) | 모델에 입력하는 변수 | 나이, 소득, 광고비 |
| 목표변수(Target Variable, Y) | 모델이 예측하거나 설명하려는 변수 | 매출액, 합격 여부 |

※ 설명변수와 입력변수는 유사하게 사용되지만, 설명변수는 변수의 분석적 역할을, 입력변수는 모델에 투입되는 역할을 강조한다.

# 2. Data Type과 Data Structure

## 2-1. Data Type (자료형 / 값의 타입)

데이터가 어떤 종류의 값인지 정의하는 개념이다.

- 프로그램에서 값의 표현 방식과 가능한 연산을 결정한다.
- 예시: `int`, `float`, `str`, `bool`

## 2-2. Data Structure (자료구조 / 데이터 구조)

여러 데이터를 저장하고 조직하며 접근하기 위해 어떤 형태의 구조에 담을 것인지 정의하는 개념이다.

- 데이터의 저장 및 관리 방식
- 예시: `list`, `tuple`, `dict`, `set`, `Series`, `DataFrame`, `ndarray`

## 2-3. Data Type과 Data Structure의 차이

| 구분 | Data Type | Data Structure |
|---|---|---|
| 의미 | 값의 종류 | 데이터를 담고 관리하는 구조 |
| 목적 | 값의 표현과 연산 | 데이터의 저장과 접근 |
| 예시 | int, float, str, bool | list, tuple, dict, set |
| 라이브러리 예시 | int64, float64, datetime64 | Series, DataFrame, ndarray |

**핵심 정리**

- Data Type = 데이터 자체가 어떤 종류의 값인가?
- Data Structure = 데이터를 어떤 형태로 저장하고 관리할 것인가?

예를 들어 정형 데이터를 Python의 Pandas DataFrame이라는 자료구조에 담을 수 있다.

**정형 데이터를 DataFrame에 담는 이유**

데이터 분석, 탐색(EDA), 전처리, 필터링, 그룹별 집계 등을 편리하게 수행하기 위해서이다.

# 3. Python 자료구조와 자료형

## 3-1. 자료구조(Data Structure)

| 구분 | Python 기본 자료구조 | NumPy 자료구조 | Pandas 자료구조 |
|---|---|---|---|
| 자료구조 | list, tuple, dict, set | ndarray | Series, DataFrame |
| 특징 | 순서, 키-값, 집합 등 다양한 데이터 관리 | 하나의 dtype을 갖는 다차원 배열 | 인덱스를 가진 1차원 데이터 및 행과 열로 구성된 표 |
| 주요 작업 | 일반적인 프로그램의 데이터 저장 및 관리 | 배열 기반 수치 계산, 행렬 연산 | 표 데이터 정리, 탐색, 분석, 결측값 처리, 그룹별 집계 |
| 사용 예 | 다양한 형태의 데이터를 간단하게 관리할 때 | 많은 수치에 동일한 계산을 적용할 때 | 열 이름과 행 인덱스를 활용해 표를 분석할 때 |

- 데이터의 형태와 수행할 작업에 맞게 자료구조를 선택한다.
- 필요에 따라 서로 다른 자료구조로 변환하여 사용할 수 있다.

## 3-2. Python 기본 자료형(Data Type)

| 자료형 | 의미 | 설명 | 예시 |
|---|---|---|---|
| int | 정수형 | 소수점이 없는 숫자 | `10`, `-5` |
| float | 실수형 | 소수점을 포함하는 숫자 | `3.14`, `-2.5` |
| str | 문자열 | 문자와 텍스트 데이터 | `"Python"` |
| bool | 불리언형 | 참 또는 거짓 | `True`, `False` |
| complex | 복소수형 | 실수부와 허수부로 구성 | `3+2j` |

## 3-3. Pandas 자료형(Data Type)

| 자료형 | 의미 | 설명 |
|---|---|---|
| int64 | 정수형 | 64비트 정수 |
| float64 | 실수형 | 64비트 부동소수점 |
| bool | 불리언형 | True 또는 False |
| object | 객체형 | 문자열 등 다양한 Python 객체 저장 가능 |
| string | 문자열형 | 문자열 전용 자료형 |
| category | 범주형 | 반복되는 범주 데이터를 효율적으로 표현 |
| datetime64 | 날짜/시간형 | 날짜와 시간 데이터 |

## 3-4. NumPy 자료형(Data Type)

| 자료형 | 의미 |
|---|---|
| int32 / int64 | 정수형 |
| float32 / float64 | 실수형 |
| bool_ | 불리언형 |
| datetime64 | 날짜 및 시간 |
| timedelta64 | 시간 간격 |
| complex64 / complex128 | 복소수형 |

※ NumPy의 ndarray는 일반적으로 하나의 배열에 동일한 dtype을 사용한다.

# 4. Python 기본 자료구조

## 4-1. 숫자형(Numeric Type)

수학적인 연산을 위해 사용되는 데이터 유형이다.

### ① 정수형(Integer)

- 소수점이 없는 숫자
- `int` 타입
- 양수, 음수, 0을 표현

```python
a = 10
b = -5

print(type(a))
print(type(b))
```

### ② 부동소수점(Floating Point)

- 소수점을 포함하는 숫자
- `float` 타입
- 실수를 표현

```python
a = 3.14
b = -2.5

print(type(a))
```

### ③ 복소수형(Complex)

- 실수부와 허수부로 구성된 숫자
- `complex` 타입
- 허수부를 `j`로 표현

```python
a = 3 + 2j

print(type(a))
print(a.real)
print(a.imag)
```

## 4-2. 문자열(String)

단어, 문장과 같은 일련의 텍스트 데이터를 나타내는 자료형이다.

**특징**

- `str` 타입을 사용한다.
- 작은따옴표(`'`)와 큰따옴표(`"`) 모두 사용 가능하다.
- 따옴표 안에 작성된 문자들이 문자열로 정의된다.
- 시퀀스(Sequence) 자료형으로 문자들이 순서대로 배열된다.

```python
name = "Python"
message = 'Hello World'

print(name)
print(message)
print(type(name))
```

## 4-3. 불리언(Boolean)

`True`와 `False` 두 가지 값을 갖는 자료형이다.

**특징**

- 진실 또는 거짓을 나타낸다.
- 조건을 판단할 때 많이 사용한다.
- `if`, `while` 등의 제어문에서 조건식으로 활용한다.
- 두 값의 비교 결과로 불리언 값을 얻을 수 있다.

```python
a = 10
b = 5

print(a > b)   # True
print(a < b)   # False
print(a == b)  # False
```

# 5. Python 기본 자료구조의 종류

## 5-1. 리스트(List)

여러 개의 값을 순서대로 저장하는 자료구조이다.

**특징**

- 가변성(Mutable): 생성 후 크기와 요소 변경 가능
- 순서 유지: 입력된 순서대로 저장
- 중복 허용: 동일한 값을 여러 번 포함 가능
- 서로 다른 자료형의 요소를 함께 저장 가능
- 대괄호 `[]`를 사용하여 정의

**주요 기능**

| 기능 | 설명 | 메서드 |
|---|---|---|
| 인덱싱 | 인덱스를 사용하여 특정 요소 접근 | `list[index]` |
| 슬라이싱 | 리스트의 일부 추출 | `list[start:end]` |
| 추가 | 리스트 끝에 요소 추가 | `append()` |
| 제거 | 특정 요소 제거 | `remove()` |
| 제거 및 반환 | 특정 위치의 요소 제거 | `pop()` |

```python
# 리스트 생성
numbers = [10, 20, 30, 40, 50]

# 인덱싱
print(numbers[0])

# 슬라이싱
print(numbers[1:3])

# 요소 추가
numbers.append(60)

# 요소 제거
numbers.remove(30)

# 결과 확인
print(numbers)
```

**리스트 자료구조의 장단점**

- 장점: 다양한 형태의 데이터를 유연하게 관리할 수 있다.
- 단점: 대규모 수치 연산에서는 NumPy 배열보다 효율이 떨어질 수 있다.

## 5-2. 튜플(Tuple)

여러 개의 값을 순서대로 저장하는 자료구조이다.

리스트와 유사하지만 생성 이후 요소를 변경할 수 없다는 차이가 있다.

**특징**

- 불변성(Immutable): 요소의 교체, 추가, 삭제 불가능
- 순서 유지: 입력된 순서대로 저장
- 중복 허용
- 소괄호 `()`를 사용하여 정의

```python
numbers = (10, 20, 30, 40)

print(numbers[0])
print(numbers[1:3])
```

## 5-3. 딕셔너리(Dictionary)

키(Key)와 값(Value)의 쌍으로 이루어진 자료구조이다.

**특징**

- 키를 사용하여 해당 값에 접근한다.
- 키는 중복될 수 없다.
- 값은 중복될 수 있다.
- 생성 후 요소의 추가, 수정, 삭제가 가능하다.
- 중괄호 `{}`를 사용하여 정의한다.
- Python 3.7 이상에서는 삽입 순서가 보장된다.

```python
person = {
    "name": "홍길동",
    "age": 30,
    "job": "Developer"
}

# 키를 이용한 값 접근
print(person["name"])

# 값 수정
person["age"] = 31

# 요소 추가
person["city"] = "Seoul"

print(person)
```

## 5-4. 집합(Set)

중복된 요소를 허용하지 않는 자료구조이다.

**특징**

- 중복 요소 허용하지 않음
- 일반적으로 인덱스를 통한 접근 불가능
- 요소의 추가 및 삭제 가능
- 합집합, 교집합, 차집합 등의 집합 연산 지원
- 중괄호 `{}`를 사용하여 정의

```python
numbers = {1, 2, 3, 3, 4, 5}

# 중복 제거
print(numbers)

# 요소 추가
numbers.add(6)

# 요소 삭제
numbers.remove(2)

# 집합 연산
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # 합집합
print(a & b)  # 교집합
print(a - b)  # 차집합
```

※ 빈 집합은 `{}`가 아닌 `set()`으로 생성한다.

## 5-5. 인덱스(Index)

각 데이터를 구분하고 접근하기 위한 위치 또는 라벨이다.

**주요 역할**

- 특정 데이터 검색
- 데이터 정렬
- 데이터 결합
- 특정 위치의 데이터 접근

※ Python 리스트의 인덱스는 기본적으로 0부터 시작한다. Pandas의 인덱스는 정수뿐 아니라 문자열 등 다양한 라벨을 사용할 수 있다.

# 6. Pandas 자료구조

## 6-1. Pandas란?

Pandas는 Python에서 데이터 분석을 수행하기 위해 사용하는 라이브러리이다.

Series와 DataFrame이라는 데이터 구조를 제공한다.

**주요 특징**

- 데이터 처리: 필터링, 그룹화, 조인, 병합 등
- 다양한 데이터 소스 지원: CSV, Excel, JSON 등
- 결측값 처리: 데이터 내 누락된 값 탐색 및 처리
- 라벨 기반 인덱싱: 행과 열의 이름을 통해 데이터 접근

## 6-2. Series

1차원 데이터 구조이다.

- 하나의 데이터 열을 표현하는 데 사용한다.
- 데이터 값(Value)과 인덱스(Index)로 구성된다.
- 각 데이터에 인덱스 라벨을 부여한다.

```python
import pandas as pd

data = [10, 20, 30, 40]

series = pd.Series(data)

print(series)
```

## 6-3. DataFrame

행(Row)과 열(Column)로 구성된 2차원 표 형태의 데이터 구조이다.

- 행 인덱스(Index)와 열 이름(Columns)을 갖는다.
- 여러 개의 Series가 결합된 형태로 이해할 수 있다.
- CSV, Excel, JSON 등의 데이터를 불러와 분석할 수 있다.

```python
import pandas as pd

data = {
    "이름": ["철수", "영희", "민수"],
    "나이": [25, 30, 28],
    "점수": [85, 90, 95]
}

df = pd.DataFrame(data)

print(df)
```

**DataFrame 주요 기능**

| 기능 | 설명 |
|---|---|
| 데이터 조회 | 특정 행과 열의 데이터 확인 |
| 필터링 | 조건에 맞는 데이터 추출 |
| 그룹화 | 특정 기준으로 데이터 분류 |
| 결합 | 여러 데이터프레임 연결 |
| 결측값 처리 | 누락된 데이터 탐색 및 처리 |
| 통계 분석 | 평균, 합계, 최댓값, 최솟값 등 계산 |

# 7. NumPy 배열

## 7-1. NumPy란?

NumPy(Numerical Python)는 수치 연산을 효율적으로 수행하기 위한 Python 라이브러리이다.

- 다차원 배열(ndarray) 지원
- 행렬 연산 및 수학적 계산 지원
- 대규모 수치 데이터 처리에 적합

## 7-2. NumPy 배열(ndarray)

동일한 데이터 타입의 요소들로 구성된 고정 크기의 다차원 배열이다.

**주요 특징**

### ① 메모리 효율성

- 수치 데이터를 효율적으로 저장한다.
- 대규모 데이터 계산에 유리하다.

### ② 벡터화 연산(Vectorization)

- 반복문을 직접 작성하지 않고 배열 전체에 연산을 적용할 수 있다.

### ③ 다차원 지원

- 1차원 배열: 벡터
- 2차원 배열: 행렬
- 3차원 이상: 다차원 배열

```python
import numpy as np

numbers = np.array([10, 20, 30, 40])

# 배열 전체에 2를 곱함
print(numbers * 2)

# 배열 전체에 10을 더함
print(numbers + 10)
```

# 8. Python 제어문

## 8-1. 프로그램 제어 구조

프로그램의 실행 흐름을 제어하는 구조이다.

| 구분 | 정의 | 예시 |
|---|---|---|
| 순차구조 | 명령을 작성된 순서대로 실행 | 일반적인 코드 실행 |
| 선택구조 | 조건에 따라 실행할 코드를 선택 | if, elif, else |
| 반복구조 | 동일한 명령을 반복 실행 | for, while |

## 8-2. 조건문(Conditional Statement)

프로그램은 기본적으로 코드를 위에서 아래로 실행한다.

하지만 상황에 따라 서로 다른 작업을 수행해야 하는 경우가 발생한다.

**조건문이란?**

조건의 참(True) 또는 거짓(False)에 따라 실행할 코드를 선택하는 문법이다.

## 8-3. 조건식(Conditional Expression)

조건식은 참과 거짓을 판단하기 위한 식이다.

주로 비교연산자를 사용하여 조건을 작성한다.

| 연산자 | 의미 | 예시 |
|---|---|---|
| `==` | 같다 | `score == 60` |
| `!=` | 같지 않다 | `score != 60` |
| `>` | 초과 | `score > 60` |
| `<` | 미만 | `score < 60` |
| `>=` | 이상 | `score >= 60` |
| `<=` | 이하 | `score <= 60` |

## 8-4. if문

조건이 참(True)일 때 특정 코드를 실행한다.

**작성 규칙**

- `if` 뒤에 조건식을 작성한다.
- 조건식 끝에 콜론(`:`)을 붙인다.
- 조건이 참일 때 실행할 코드는 들여쓰기한다.

```python
score = 80

if score >= 60:
    print("합격입니다.")
```

## 8-5. 들여쓰기(Indentation)

조건문이나 반복문 등에 포함되는 코드의 범위를 구분하는 문법이다.

**특징**

- 같은 깊이로 들여쓴 문장들은 하나의 코드 블록을 이룬다.
- 일반적으로 공백 4칸을 사용한다.
- 들여쓰기가 끝나면 해당 코드 블록 밖의 명령이 실행된다.

```python
score = 80

if score >= 60:
    print("합격입니다.")
    print("축하합니다.")

print("프로그램 종료")
```

## 8-6. if-else문

조건이 참이면 `if`, 거짓이면 `else` 블록을 실행한다.

- 두 블록 중 하나만 실행한다.
- `else` 뒤에는 조건식을 작성하지 않는다.

```python
score = 50

if score >= 60:
    print("합격")
else:
    print("불합격")
```

## 8-7. if-elif-else문

여러 조건 중 하나를 선택하여 실행하는 문법이다.

**실행 순서**

1. 조건을 위에서 아래로 검사한다.
2. 처음으로 참이 되는 조건의 블록만 실행한다.
3. 앞의 조건이 모두 거짓이면 `else`를 실행한다.

```python
score = 85

if score >= 90:
    print("A등급")

elif score >= 80:
    print("B등급")

elif score >= 70:
    print("C등급")

else:
    print("F등급")
```

## 8-8. 여러 개의 if문과 if-elif문의 차이

| 구분 | 여러 개의 if문 | if-elif문 |
|---|---|---|
| 조건 검사 | 각각의 조건을 독립적으로 검사 | 앞 조건이 거짓일 때 다음 조건 검사 |
| 실행 결과 | 여러 조건이 참이면 여러 블록 실행 가능 | 처음 참이 되는 블록 하나만 실행 |
| 사용 목적 | 여러 조건을 각각 확인할 때 | 여러 경우 중 하나를 선택할 때 |

**예시 1. 여러 개의 if문**

```python
score = 95

if score >= 60:
    print("60점 이상")

if score >= 80:
    print("80점 이상")

if score >= 90:
    print("90점 이상")
```

실행 결과

```text
60점 이상
80점 이상
90점 이상
```

**예시 2. if-elif문**

```python
score = 95

if score >= 90:
    print("90점 이상")

elif score >= 80:
    print("80점 이상")

elif score >= 60:
    print("60점 이상")
```

실행 결과

```text
90점 이상
```

## 8-9. 논리연산자(Logical Operator)

여러 조건을 조합하거나 조건의 참과 거짓을 반대로 바꾸는 연산자이다.

| 연산자 | 의미 | 설명 |
|---|---|---|
| `and` | 그리고 | 두 조건이 모두 참이어야 참 |
| `or` | 또는 | 두 조건 중 하나 이상이 참이면 참 |
| `not` | 부정 | 참과 거짓을 반대로 변경 |

**예시**

```python
age = 25
score = 85

# and
if age >= 20 and score >= 80:
    print("조건을 모두 만족합니다.")

# or
if age >= 20 or score >= 90:
    print("조건 중 하나 이상을 만족합니다.")

# not
if not score < 60:
    print("60점 이상입니다.")
```

## 8-10. 중첩 조건문(Nested Conditional Statement)

조건문 내부에 또 다른 조건문을 사용하는 구조이다.

**사용 목적**

- 첫 번째 조건을 만족한 경우 추가 판단이 필요할 때 사용한다.
- 여러 단계의 조건을 순차적으로 확인할 때 사용한다.

```python
age = 25
score = 85

if age >= 20:
    print("성인입니다.")

    if score >= 80:
        print("우수한 성적입니다.")

    else:
        print("성적이 기준에 미달합니다.")

else:
    print("미성년자입니다.")
```

# 9. 핵심 내용 요약(Summary)

## 9-1. 데이터 분류와 자료구조의 차이

| 구분 | 핵심 질문 | 대표 유형 |
|---|---|---|
| 데이터 구조적 유형 | 데이터가 어떻게 구성되어 있는가? | 정형, 반정형, 비정형 |
| 변수 유형 | 데이터 값이 무엇을 의미하는가? | 범주형, 수치형 |
| 변수 역할 | 모델에서 어떤 역할을 하는가? | 설명변수, X, Y |
| Data Type | 값은 어떤 종류인가? | int, float, str, bool |
| Data Structure | 데이터는 어떤 구조에 담기는가? | list, dict, ndarray, DataFrame |

## 9-2. 자료구조 핵심 비교

| 자료구조 | 순서 | 수정 | 중복 | 특징 |
|---|---|---|---|---|
| list | O | O | O | 여러 데이터를 순서대로 저장 |
| tuple | O | X | O | 변경할 수 없는 데이터 저장 |
| dict | 삽입 순서 유지 | O | 키 중복 X | 키와 값의 쌍으로 저장 |
| set | X | O | X | 중복 없는 데이터 저장 |
| Series | 인덱스 기반 | O | O | 1차원 데이터 |
| DataFrame | 행 인덱스 기반 | O | O | 2차원 표 데이터 |
| ndarray | 배열 위치 기반 | O | O | 다차원 수치 배열 |

## 9-3. 최종 핵심 정리

- **Data Type**: 데이터 값의 종류를 정의한다.
- **Data Structure**: 데이터를 저장하고 관리하는 구조를 정의한다.
- **Python List**: 다양한 자료형의 데이터를 유연하게 관리한다.
- **Pandas Series**: 인덱스를 가진 1차원 데이터이다.
- **Pandas DataFrame**: 행과 열로 구성된 2차원 표 데이터이다.
- **NumPy ndarray**: 동일한 자료형을 기반으로 효율적인 수치 연산을 수행한다.
- **조건문**: 조건의 참과 거짓에 따라 프로그램의 실행 흐름을 제어한다.
