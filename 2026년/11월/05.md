# Pandas

## 1. Pandas 개요

### 1-1. Pandas란?

- 데이터를 핸들링하고 분석하는 데 사용하는 Python 라이브러리
- 데이터를 표(Table) 형태로 구성하고 분석하는 기능 지원
- 행(Row)과 열(Column)을 기반으로 대량의 데이터를 효율적으로 처리

### 1-2. 주요 기능

| 기능 | 설명 |
|---|---|
| 데이터 불러오기 및 저장 | CSV, Excel, JSON, SQL 등 |
| 데이터 정리 및 전처리 | 결측치 처리, 타입 변환, 중복 제거, 필터링 |
| 데이터 가공 및 변환 | 새로운 열 생성, 조건에 따른 값 변경 |
| 데이터 요약 및 집계 | `groupby()`를 이용한 평균, 합계, 개수 계산 |
| 데이터 결합 | `merge()`, `join()`으로 여러 데이터 연결 |
| 데이터 탐색 및 기초 분석 | 기술통계, 간단한 시각화 |

## 2. 데이터 분석 파이프라인(Data Pipeline)

### 2-1. 데이터 파이프라인이란?

- 데이터(Raw Data)를 소스로부터 수집하여 변환 및 적재를 거쳐 분석이나 ML 학습에 활용할 수 있는 상태로 만드는 자동화된 데이터 이동 및 처리 흐름
- 데이터가 수집된 이후 분석에 활용되기까지의 전체적인 처리 과정

**데이터 분석 파이프라인 구조**

```text
데이터 소스
    ↓
데이터 수집
    ↓
데이터 처리 및 변환
    ↓
데이터 저장
    ↓
분석 및 모델링
```

### 2-2. Pandas를 활용한 데이터 파이프라인 예제

```python
import pandas as pd

# 1. CSV 파일 불러오기
df = pd.read_csv("/content/titanic.csv")

# 2. 결측치 처리 (Age 열의 중앙값으로 대체)
df["Age"] = df["Age"].fillna(df["Age"].median())

# 3. Pclass를 기준으로 Fare 평균 계산
summary = df.groupby("Pclass")["Fare"].mean()

# 4. 결과 저장
summary.to_csv("pclass_fare_mean.csv")
```

**처리 순서**

1. CSV 파일 불러오기
2. 결측치 처리
3. 그룹별 평균 계산
4. 결과 파일 저장

## 3. Pandas의 데이터 구조

Pandas는 크게 Series와 DataFrame 두 가지 데이터 구조를 사용한다.

### 3-1. Series(시리즈)

- 1차원 데이터 구조
- 하나의 열(Column)과 유사한 형태
- 인덱스(Index)와 값(Value)으로 구성

```python
import pandas as pd

data = [10, 20, 30, 40]

series = pd.Series(data)

print(series)
print(type(series))
```

### 3-2. DataFrame(데이터프레임)

- 2차원 데이터 구조
- 행(Row)과 열(Column)로 구성된 표 형태
- 여러 개의 Series가 결합된 구조로 이해할 수 있음

```python
data = {
    "Name": ["Kim", "Lee", "Park"],
    "Age": [25, 30, 35],
    "Score": [80, 90, 85]
}

df = pd.DataFrame(data)

print(df)
print(type(df))
```

### 3-3. Series와 DataFrame 비교

| 구분 | Series | DataFrame |
|---|---|---|
| 차원 | 1차원 | 2차원 |
| 구조 | 인덱스 + 값 | 행 + 열 |
| 형태 | 하나의 열 | 여러 행과 열로 구성된 표 |
| 생성 함수 | `pd.Series()` | `pd.DataFrame()` |

**활용:** 데이터 분석 과정에서 Series와 DataFrame을 상황에 따라 유기적으로 변환하며 사용한다.

## 4. 데이터 구조 변환

### 4-1. 리스트(List) → Series 변환

- `pd.Series()` 함수를 사용하여 리스트를 Series로 변환
- `type()` 함수로 자료형 확인
- Series로 변환하면 Pandas에서 제공하는 다양한 연산 기능 사용 가능

```python
data = [10, 20, 30, 40]

series = pd.Series(data)

print(series)
print(type(series))
```

### 4-2. 리스트(List) → DataFrame 변환

- `pd.DataFrame()` 함수를 사용하여 리스트를 DataFrame으로 변환
- `type()` 함수로 데이터 구조 확인
- `columns` 속성으로 열 이름 확인
- `rename()` 함수로 열 이름 변경

```python
data = [
    ["Kim", 25],
    ["Lee", 30],
    ["Park", 35]
]

df = pd.DataFrame(data, columns=["Name", "Age"])

# 데이터프레임의 열 이름 확인
print(df.columns)

# 열 이름 변경
df = df.rename(columns={"Name": "Student"})
```

**열 이름 변경 기본 문법**

```python
df.rename(columns={"기존 열 이름": "변경할 열 이름"})
```

### 4-3. 딕셔너리(Dictionary) → DataFrame 변환

- 딕셔너리를 `pd.DataFrame()` 함수의 인자로 전달하여 DataFrame 생성
- 딕셔너리의 Key는 열 이름, Value는 해당 열의 데이터가 됨

```python
data = {
    "Name": ["Kim", "Lee", "Park"],
    "Age": [25, 30, 35]
}

df = pd.DataFrame(data)

print(df)
print(type(df))
```

### 4-4. DataFrame의 주요 속성

| 속성 | 설명 | 사용 예시 |
|---|---|---|
| `shape` | 행과 열의 개수 | `df.shape` |
| `index` | 행 인덱스 정보 | `df.index` |
| `columns` | 열 이름 정보 | `df.columns` |
| `values` | 데이터 값 확인 | `df.values` |
| `dtypes` | 각 열의 데이터형 확인 | `df.dtypes` |

```python
print(df.shape)
print(df.index)
print(df.columns)
print(df.values)
print(df.dtypes)
```

## 6. DataFrame 데이터 조작

### 6-1. 행과 열 삭제하기 : `drop()`

- `drop()` 함수를 사용하여 특정 행 또는 열 삭제
- `axis=0`: 행 삭제
- `axis=1`: 열 삭제

```python
# 특정 행 삭제
df = df.drop([0])

# 특정 열 삭제
df = df.drop(["Age"], axis=1)
```

### 6-2. 차트 만들기 : `plot()`

- `plot()` 함수를 사용하여 데이터 시각화
- 기본 차트 형태는 꺾은선 그래프

```python
df.plot()
```

### 6-3. 특정 열을 기준으로 정렬 : `sort_values()`

- DataFrame에 포함된 특정 열을 기준으로 데이터 정렬
- 오름차순: `ascending=True`
- 내림차순: `ascending=False`

```python
# Age 기준 오름차순
df.sort_values(by="Age")

# Age 기준 내림차순
df.sort_values(by="Age", ascending=False)
```

### 6-4. 평균값 계산 : `mean()`

- 특정 열 또는 여러 열의 평균값 계산
- 새로운 열에 평균값을 추가하는 경우 계산 결과를 대입

```python
# Age 평균 계산
mean_age = df["Age"].mean()

# 새로운 열 추가
df["Mean_Age"] = mean_age
```

## 9. DataFrame 복사 및 데이터 추가

### 9-1. 데이터프레임 복사 : `copy()`

new_df = pd.concat([df, copy_df], ignore_index=True)

df.loc[0, "Age"] = 30

## 10. 인덱스(Index)

### 10-1. 인덱스란?

- 데이터를 식별하고 선택하기 위해 행 또는 열에 붙이는 라벨(Label)
- 숫자 또는 문자열 등으로 지정 가능
- 일반적으로 DataFrame에서 행을 식별하는 라벨을 의미
- 별도로 지정하지 않으면 0부터 시작하는 정수 인덱스 자동 생성
- 이름, 학번, 날짜 등 특정 속성을 행 인덱스로 지정 가능

### 10-2. 새로운 인덱스 지정 : `set_index()`

- 특정 열을 행 인덱스로 지정
- 기존 인덱스 대신 새로운 인덱스를 사용하거나 기존 인덱스를 유지할 수 있음

```python
# Name 열을 인덱스로 지정
df = df.set_index("Name")
```

**append 옵션**

- `append=True`: 기존 인덱스를 유지하면서 새로운 인덱스 추가
- `append=False`: 기존 인덱스를 새로운 인덱스로 대체 (기본값)

```python
df = df.set_index("Name", append=True)
```

### 10-3. 기존 인덱스 초기화 : `reset_index()`

- 기존 인덱스를 초기화하고 기본 정수 인덱스로 변경
- `drop=True` 옵션을 사용하면 기존 인덱스를 열로 추가하지 않고 삭제

```python
df = df.reset_index(drop=True)
```

### 10-4. 날짜 인덱스 만들기 : `pd.date_range()`

- 지정한 시작 날짜와 기간을 기준으로 날짜 인덱스 생성
- 날짜별 데이터 분석 및 시계열 분석에 활용

```python
dates = pd.date_range(
    start="2026-01-01",
    periods=5,
    freq="D"
)

print(dates)
```

### 10-5. 인덱스 정렬 : `sort_index()`

- 인덱스를 기준으로 데이터 정렬
- 오름차순: `ascending=True` (기본값)
- 내림차순: `ascending=False`

```python
# 오름차순
df.sort_index()

# 내림차순
df.sort_index(ascending=False)
```

## 11. DataFrame 데이터 접근

### 11-1. 행(Row), 열(Column), 셀(Cell) 접근 방식

| 구분 | 접근 방법 | 설명 |
|---|---|---|
| 행 접근 | `df.loc[인덱스]` | 인덱스 라벨 기준 |
| 행 접근 | `df.iloc[행번호]` | 정수 위치 기준 |
| 열 접근 | `df["열이름"]` | 열 이름 기준 |
| 셀 접근 | `df.loc[행인덱스, 열이름]` | 인덱스 라벨 기준 |
| 셀 접근 | `df.iloc[행번호, 열번호]` | 정수 위치 기준 |

```python
# 행 접근
df.loc[0]
df.iloc[0]

# 열 접근
df["Age"]

# 셀 접근
df.loc[0, "Age"]
df.iloc[0, 1]
```

### 11-2. Series 값 접근 방식

Series는 다음과 같은 방법으로 값을 선택할 수 있음.

- 인덱스 라벨을 사용한 접근
- 정수 위치를 사용한 접근
- 슬라이싱을 이용한 여러 값 접근
- 조건식을 이용한 값 접근

```python
series = pd.Series(
    [10, 20, 30, 40],
    index=["A", "B", "C", "D"]
)

# 인덱스 라벨로 접근
print(series.loc["A"])

# 정수 위치로 접근
print(series.iloc[0])

# 슬라이싱
print(series.iloc[0:2])

# 조건 검색
print(series[series > 20])
```

### 11-3. 단순 인덱스를 이용한 범위 지정

- 슬라이싱을 사용하여 원하는 범위의 행 추출
- `df[:3]`: 처음부터 3개 행 추출
- `df.iloc[:3, :]`: 처음 3개 행과 모든 열 추출

```python
# 처음 3개 행
df[:3]

# 처음 3개 행과 모든 열
df.iloc[:3, :]
```

**주의:** Python의 슬라이싱은 종료 위치를 포함하지 않음.

### 11-4. 지정 범위의 행 가져오기

```python
# 0번째 행부터 4번째 행 직전까지
df[0:4]

# 처음부터 끝까지 역순으로 정렬
df[::-1]
```

### 11-5. 지정 범위의 열 가져오기

- `columns` 속성을 사용하여 열 이름 확인
- 열의 위치 번호를 이용하여 특정 열 선택 가능

```python
# 열 개수 확인
print(len(df.columns))

# 첫 번째 열 이름 확인
print(df.columns[0])

# 첫 번째 열 선택
df[df.columns[0]]
```

### 11-6. 열 이름과 위치로 데이터 가져오기

- 여러 열을 선택할 때는 열 이름을 리스트 형태로 입력
- `iloc[]`를 이용하면 열의 위치 번호로 선택 가능

```python
# 특정 열 선택
df[["Name", "Age"]]

# 열 위치로 선택
df.iloc[:, 0]

# 첫 번째부터 세 번째 열 직전까지
df.iloc[:, 0:2]

# 모든 행에서 첫 번째, 세 번째 열 선택
df.iloc[:, [0, 2]]
```

### 11-7. 인덱스 이름 기준 데이터 가져오기 : `loc[]`

- 행 인덱스의 라벨을 기준으로 데이터 선택
- 하나 또는 여러 개의 행 지정 가능
- 특정 행에서 필요한 열만 선택 가능

```python
# 특정 인덱스 선택
df.loc[0]

# 여러 인덱스 선택
df.loc[[0, 1]]

# 특정 행과 열 선택
df.loc[0, "Age"]

# 특정 행에서 여러 열 선택
df.loc[0, ["Name", "Age"]]

# 모든 행에서 특정 열 선택
df.loc[:, ["Name", "Age"]]
```

### 11-8. 인덱스 순서 기준 데이터 가져오기 : `iloc[]`

- 정수 위치를 기준으로 데이터 선택
- 행과 열의 위치 번호를 사용
- 쉼표를 기준으로 행과 열을 구분
- 슬라이싱 및 증가값 지정 가능

```python
# 첫 번째 행
df.iloc[0]

# 첫 번째 행의 두 번째 열
df.iloc[0, 1]

# 처음 3개 행
df.iloc[:3]

# 모든 행의 첫 번째 열
df.iloc[:, 0]

# 처음 3개 행의 처음 2개 열
df.iloc[:3, :2]

# 행을 역순으로 출력
df.iloc[::-1]
```

## 12. 데이터 정렬

### 12-1. 인덱스 기준 정렬 : `sort_index()`

- 행 인덱스를 기준으로 데이터 정렬
- 오름차순: `ascending=True`
- 내림차순: `ascending=False`

```python
df.sort_index(ascending=True)

df.sort_index(ascending=False)
```

### 12-2. 열 기준 정렬 : `sort_values()`

- 특정 열에 포함된 값을 기준으로 데이터 정렬
- 여러 개의 열을 기준으로 정렬 가능

# Age 기준 오름차순
df.sort_values(by="Age")

# Age 기준 내림차순
df.sort_values(by="Age", ascending=False)

# Age와 Pclass 기준 정렬
df.sort_values(

    ascending=[True, False]
)

## 13. 데이터 집계 및 분석

### 13-1. 피벗테이블 : `pivot_table()`

- DataFrame에 포함된 열 중 두 개의 열을 각각 행과 열 인덱스로 설정
- 행과 열이 만나는 지점에 집계된 값을 표시
- 데이터를 여러 기준으로 요약하고 비교할 때 활용

```python
pivot = pd.pivot_table(
    df,
    index="Pclass",
    columns="Sex",
    values="Fare",
    aggfunc="mean"
)

print(pivot)
```

**구조 이해**

- 왼쪽 인덱스: 행 인덱스
- 상단 인덱스: 열 인덱스
- 교차 지점: 집계 결과

### 13-2. 그룹화 : `groupby()`

- 특정 열을 기준으로 동일한 데이터를 그룹화
- 그룹별 개수, 합계, 평균 등의 통계 계산 가능
- 동일한 특성을 가진 데이터끼리 묶어서 분석할 때 활용

```python
# Pclass 기준 그룹화
df.groupby("Pclass")

# 그룹별 Fare 평균
df.groupby("Pclass")["Fare"].mean()

# 그룹별 데이터 개수
df.groupby("Pclass")["Fare"].count()

# 그룹별 Fare 합계
df.groupby("Pclass")["Fare"].sum()

# 두 개 이상의 열을 기준으로 그룹화
df.groupby(["Pclass", "Sex"])["Fare"].mean()
```

### 13-3. Stack과 Unstack

**stack()**

- 열 방향으로 구성된 데이터를 행 방향으로 변환
- 열 인덱스를 행 인덱스로 이동시키는 형태

**unstack()**

- 행 인덱스로 구성된 데이터를 열 방향으로 변환
- 행 인덱스의 한 레벨을 열 인덱스로 이동

```python
# 행 인덱스 방향으로 변환
stacked = pivot.stack()

# 열 인덱스 방향으로 변환
unstacked = stacked.unstack()
```

## 14. 조건 검색 및 Boolean Index

### 14-1. Boolean Index란?

- 특정 열에 조건을 설정하여 원하는 데이터만 추출하는 방식
- 조건의 결과는 Boolean 형태인 `True` 또는 `False`로 반환
- `True`에 해당하는 데이터만 선택 가능

```python
# Age가 30 이상인 데이터
condition = df["Age"] >= 30

print(condition)

# 조건에 해당하는 데이터만 추출
df[condition]
```

### 14-2. loc[]와 조건식 활용

- 조건식과 표시할 열 이름을 함께 지정하여 필요한 데이터만 추출
- 쉼표를 기준으로 행 조건과 열 선택을 구분
- 필요한 열을 리스트 형태로 지정 가능

```python
# Age가 30 이상인 행에서 모든 열 추출
df.loc[df["Age"] >= 30]

# Age가 30 이상인 행에서 Name과 Fare만 추출
df.loc[df["Age"] >= 30, ["Name", "Fare"]]

# Age가 30 이상인 행에서 특정 열 범위 추출
df.loc[df["Age"] >= 30, "Name":"Fare"]
```

### 14-3. isin() 함수

- 특정 열에 원하는 데이터가 존재하는지 확인
- 조건에 해당하면 `True`, 해당하지 않으면 `False` 반환
- 여러 개의 값을 대상으로 조건 검색할 때 활용

```python
# Pclass가 1 또는 3인 데이터 확인
df["Pclass"].isin([1, 3])
```

### 14-4. isin()과 loc[]를 활용한 조건 검색

```python
# Pclass가 1 또는 3인 데이터 추출
df.loc[df["Pclass"].isin([1, 3])]

# Pclass가 1 또는 3인 데이터에서 Name과 Age만 추출
df.loc[
    df["Pclass"].isin([1, 3]),
    ["Name", "Age"]
]
```

## 15. 문자열 처리

### 15-1. 문자열 공백 및 문자 제거

문자열의 양쪽 또는 한쪽에 포함된 공백이나 지정 문자를 제거할 때 사용한다.

| 함수 | 설명 |
|---|---|
| `strip()` | 문자열 양쪽의 공백 또는 지정 문자 제거 |
| `lstrip()` | 문자열 왼쪽의 공백 또는 지정 문자 제거 |
| `rstrip()` | 문자열 오른쪽의 공백 또는 지정 문자 제거 |

```python
text = "  Python Pandas  "

# 양쪽 공백 제거
print(text.strip())

# 왼쪽 공백 제거
print(text.lstrip())

# 오른쪽 공백 제거
print(text.rstrip())
```

**Pandas Series에서 활용**

```python
# 문자열 열의 양쪽 공백 제거
df["Name"] = df["Name"].str.strip()

# 왼쪽 공백 제거
df["Name"] = df["Name"].str.lstrip()

# 오른쪽 공백 제거
df["Name"] = df["Name"].str.rstrip()
```

## 17. 핵심 개념 정리

1. **Series** : 하나의 열과 같은 1차원 데이터 구조
2. **DataFrame** : 행과 열로 구성된 2차원 데이터 구조
3. **Index** : 데이터를 식별하기 위한 행의 라벨
4. **loc[]** : 인덱스 라벨을 기준으로 데이터 선택
5. **iloc[]** : 정수 위치를 기준으로 데이터 선택
6. **groupby()** : 특정 기준으로 데이터를 그룹화하여 집계
7. **pivot_table()** : 행과 열을 기준으로 데이터를 요약
8. **Boolean Index** : 조건식의 True와 False를 이용하여 데이터 선택
9. **Data Pipeline** : 데이터 수집부터 처리, 저장, 분석까지 이어지는 데이터 처리 흐름

**Pandas의 핵심 목적은 데이터를 읽고, 정리하고, 가공하고, 분석하여 의미 있는 결과를 도출하는 것이다.**
