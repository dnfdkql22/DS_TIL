# 머신러닝 정리: 회귀 · 로지스틱 회귀 · SVM

## 1. 다중 선형 회귀와 다항 회귀

### 다중 선형 회귀 (Multiple Linear Regression)
- 여러 개의 입력 변수로 하나의 연속형 값을 예측하는 선형 모델

$$
\hat{y} = b_0 + b_1 x_1 + b_2 x_2 + \cdots + b_n x_n
$$

### 다항 회귀 (Polynomial Regression)
- 입력 특성을 다항식으로 확장한 뒤 선형 회귀를 적용
- 제곱항 등을 추가해 **비선형 관계**를 표현할 수 있음
- 특성은 비선형이지만, 계수 $b$에 대해서는 여전히 선형이라 선형 회귀로 학습 가능

$$
\hat{y} = b_0 + b_1 x + b_2 x^2 + \cdots + b_d x^d
$$

## 2. 차원에 따른 결정 경계

**예측 결과(회귀)의 모양**

- 입력 변수가 1개면 예측 결과는 **직선**
- 입력 변수가 2개면 예측 결과는 3차원 공간에서의 **평면**
- 입력 변수가 더 많아지면 예측 결과는 **초평면**

**클래스를 나누는 결정 경계(분류)의 모양**

| 공간 | 결정 경계 |
| :--- | :--- |
| 2차원 공간 | 1차원 **직선**으로 클래스 구분 |
| 3차원 공간 | 2차원 **평면**으로 클래스 구분 |
| 4차원 공간 | 3차원 **초평면**으로 클래스 구분 |
| $n$차원 공간 | $(n-1)$차원 초평면으로 클래스 구분 |

## 3. 로지스틱 회귀 (Logistic Regression)

- 독립 변수의 선형 결합을 이용해 사건의 발생 가능성을 예측하는 통계 기법

### 선형 회귀 vs 로지스틱 회귀

| 구분 | 선형 회귀 | 로지스틱 회귀 |
| :--- | :--- | :--- |
| 목적 | 연속형 값 예측 | 분류 (주로 이진 분류) |
| 예시 | 주택 가격, 체중, 온도 | 스팸 여부, 합격/불합격 |
| 출력 | 실수 전체 $(-\infty, +\infty)$ | 특정 클래스에 속할 확률 $(0, 1)$ |
| 식 | $\hat{y} = b_0 + b_1 x$ | $p = \sigma(z) = \dfrac{1}{1 + e^{-z}}$ |
| 학습 기준 | 평균 제곱 오차(MSE) 최소화 | 로그 손실(크로스 엔트로피) 최소화 |

### 선형 회귀 복습
- **모델**: 두 변수 사이의 선형 관계를 가정
  - 독립 변수 $X$가 변할 때 종속 변수 $Y$가 일정한 비율로 변한다고 가정
- **함수**: $b_0$는 절편, $b_1$은 기울기(회귀 계수)

$$
\hat{y} = b_0 + b_1 x
$$

- **오차 측정**: 평균 제곱 오차(MSE)로 예측값과 실제값의 차이를 최소화하도록 학습

$$
\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} \left( y_i - \hat{y}_i \right)^2
$$

### 로지스틱 회귀의 핵심 아이디어
- 분류 문제에 사용 (주로 이진 분류)
- 출력값은 특정 클래스에 속할 **확률**
- 특정 클래스에 속할 확률의 **로그 오즈**를 입력 변수의 선형 조합으로 모델링
- 이를 **시그모이드 함수**로 변환해 확률을 추정
- 추정한 확률에 **임계값**을 적용해 최종 클래스를 결정
- 이름에 '회귀'가 있지만 일반적으로 **분류 모델**로 사용

## 4. 오즈와 로그 오즈 (Odds, Log-Odds)

로그 오즈는 확률을 분류 모델이 다루기 쉬운 숫자 축으로 바꾼 값이다.

### ① 확률을 오즈로 변환
- 오즈는 성공 확률과 실패 확률의 비율
- 확률이 $p$일 때:

$$
\text{Odds} = \frac{p}{1 - p}
$$

- 범위: $0 \sim +\infty$

### ② 오즈에 자연로그 적용

$$
\text{log-odds} = \text{logit}(p) = \ln\left( \frac{p}{1 - p} \right)
$$

- 범위: $-\infty \sim +\infty$
- 음수부터 양수까지 모든 실숫값이 가능해져서 **선형식으로 다루기 쉬워짐**
- 그래서 입력 변수의 선형 조합으로 모델링하기에 적합
- 로지스틱 회귀는 **로그 오즈가 입력 변수의 선형 조합으로 표현된다**고 가정

---

## 5. 로지스틱 회귀의 계산 순서

> 입력의 선형 점수를 로그 오즈로 해석하고, 시그모이드로 확률로 바꾸는 모델

1. **선형 점수 계산**: 입력 $x$로 선형 점수 $z$를 계산

$$
z = b_0 + b_1 x_1 + b_2 x_2 + \cdots + b_n x_n
$$

2. **로그 오즈로 가정**: 이 점수 $z$를 예측 확률의 로그 오즈로 봄

$$
z = \ln\left( \frac{p}{1 - p} \right)
$$

3. **시그모이드 적용**: 위 식을 $p$에 대해 풀면 확률값이 나옴

$$
p = \sigma(z) = \frac{1}{1 + e^{-z}}
$$

4. **클래스 결정**: 특정 클래스에 속할 확률을 추정하고 임계값(보통 0.5)으로 분류

$$
\hat{y} =
\begin{cases}
1 & (p \ge 0.5) \\
0 & (p < 0.5)
\end{cases}
$$

## 6. 시그모이드 함수 (Sigmoid Function)

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

- 입력값을 받아 출력값을 0과 1 사이의 확률로 변환
- 선형 회귀 모델의 출력을 확률로 해석할 수 있게 해 줌

### 곡선 모양
- S자 형태의 곡선
- 입력값이 양의 무한대로 가면 출력값은 **1에 수렴**
- 입력값이 음의 무한대로 가면 출력값은 **0에 수렴**
- $z = 0$일 때 출력값은 $0.5$

$$
\lim_{z \to +\infty} \sigma(z) = 1, \qquad \lim_{z \to -\infty} \sigma(z) = 0, \qquad \sigma(0) = 0.5
$$

### 결정 경계
- 시그모이드 출력값이 0.5 이상이면 클래스 1, 그렇지 않으면 클래스 0으로 분류
- $\sigma(z) \ge 0.5$는 $z \ge 0$과 같으므로, 결정 경계는 $z = 0$인 직선(평면, 초평면)

### 시그모이드 함수의 역할
- 이진 분류에 선형 회귀를 적용할 수 있게 해 줌
- 시그모이드 함수를 적용해 출력을 0과 1 사이의 값으로 제한
- $X$ 값이 커질수록 $Y$ 값이 1에 가까워지는 비선형 관계를 형성 (계수 $b_1 > 0$일 때)

---

## 7. SVM (Support Vector Machine, 서포트 벡터 머신)

> 두 클래스를 나누는 경계 중에서, 양쪽 데이터로부터 가능한 한 여유 있게 떨어진 경계를 찾는 모델

- 지도 학습의 일종으로, 분류 문제에 쓰이는 강력하고 유연한 머신러닝 모델
- 분류 SVM은 서로 다른 클래스를 구분하면서 **마진을 크게 확보하는** 결정 경계를 학습
- **선형 SVM**: 입력 공간에서 선형 경계를 찾음
- **커널 SVM**: 원래 입력 공간에서 비선형 경계도 표현 가능
- 결정 경계는 **서포트 벡터**라는 일부 훈련 데이터에 의해 결정됨

### 주요 개념

| 개념 | 설명 |
| :--- | :--- |
| 서포트 벡터 | 결정 경계와 마진을 정하는 데 직접 영향을 주는 훈련 데이터 포인트 |
| 결정 경계 | 서로 다른 클래스를 분리하는 경계. 선형 SVM에서는 직선, 평면, 초평면으로 표현 |
| 마진 | 결정 경계 양쪽에 확보하려는 여유 폭 |
| 초평면 (Hyperplane) | 속성 공간에서 서로 다른 클래스를 분리하는 결정 경계 |

선형 SVM의 결정 경계(초평면)는 다음처럼 쓸 수 있다.

$$
\mathbf{w} \cdot \mathbf{x} + b = 0
$$
