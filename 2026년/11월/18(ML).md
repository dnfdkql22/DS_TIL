# ■ ML 모델 학습 - Classification

* 일대다 분류(One-vs-Rest)는 다중 클래스 분류 문제를 여러 개의 이진 분류 문제로 변환하여 해결하는 기법

* 분류기가 기본적으로 이진 분류만을 지원할 때 유용

* 한 번에 하나의 클래스를 양성(Positive) 클래스로 간주하고 나머지를 음성(Negative) 클래스로 취급하여 분류기를 훈련

# ■ ML 모델 학습 - Regression

* 회귀 문제
  - 기존 데이터를 통한 학습 후 새로운 데이터의 결과값 예측
  - 데이터들로부터 가장 오차가 적은 회귀선 계산

# ■ 회귀(Regression)

* 라틴어 어원 regressio = "되돌아감, 돌아옴"
  - re(뒤로, 다시) + gradi(걷다, 나아가다)
  - "뒤로 걸어감 / 다시 돌아감"

* 통계학에서의 유래
  - 19세기 말 영국의 과학자 프랜시스 골턴이 부모와 자식의 키 관계를 연구하던 중,
    - 키가 매우 큰 부모의 자녀는 부모보다 다소 작은 경향
    - 키가 매우 작은 부모의 자녀는 부모보다 다소 큰 경향
  - 값이 평균 쪽으로 되돌아가는 경향을 발견
  - 이 현상을 "Regression toward the Mean"(평균으로의 회귀)라고 명명

○ 회귀 관련 개념 비교

| 구분 | 정의 | 내용 |
|---|---|---|
| 통계 | 평균으로의 회귀 | 극단적인 관측값을 보인 집단이 관련된 다른 관측이나 반복 측정에서는 평균에 더 가까운 값을 보이는 경향 |
| ML의 회귀 | 수치형 값 예측 ML 모델 | 입력변수의 정보를 이용하여 수치형 목표값을 예측하는 과제 |
| 회귀분석 | 통계적 방법 | 하나 이상의 설명변수와 종속변수 사이의 관계를 모형화하고, 이를 해석하거나 예측하는 통계모델 |

# ■ Neural Network - 인공 신경망

* 하나의 독립된 모델
* 머신러닝 및 인공지능 기술의 범주에 속하는 방법론과 기술

# ■ KNN : K-Nearest Neighbor

* K : 클래스를 판단하기 위해 활용되는 거리가 가까운 데이터 개수
* 주변(이웃)에서 더 많은 데이터가 포함되어 있는 범주로 분류하는 방식

※ 추론 Process

- 거리 계산
- 이웃 선택
- 다수결 결정

* 새로운 데이터가 들어왔을 때 가장 가까이에 있는 K개의 기존 데이터와의 거리를 계산해 다수결로 소속 클래스를 결정하는 알고리즘

○ 맨해튼 거리(Manhattan Distance)

- 가로, 세로 방향으로 각각 얼마나 이동해야 하는지를 더한 거리
- 이동 경로에 제약이 있거나, 각 항목의 차이를 합산하고 싶을 때 사용

○ 유클리디안 거리(Euclidean Distance)

- 두 데이터 포인트 사이의 직선거리
- 각 좌표 차이를 이용하여 계산하는 거리

○ KNN 모델의 학습

- 새로운 데이터 포인트가 주어졌을 때, 가장 가까운 K개의 이웃을 찾아 이웃 중 가장 많은 클래스를 새로운 데이터의 클래스로 결정

○ Process

- 거리 계산 : 새로운 데이터와 모든 훈련 데이터 포인트 간의 거리 계산
- 이웃 선택 : 계산된 거리 중 가장 가까운 K개의 이웃 선택
- 예측 : 선택된 K개의 이웃의 레이블을 기반으로 다수결 투표(분류)나 평균 계산(회귀)을 통해 새로운 데이터의 레이블이나 값 예측

○ Lazy Learning (게으른 학습)

- 모델 학습 단계에서 별도의 일반화된 예측 모델을 미리 생성하지 않고 훈련 데이터를 저장
- 테스트 데이터가 들어오면 그때 거리 계산 및 이웃 탐색을 수행하기 때문에 게으른 학습이라고 표현
- KNN은 대표적인 Lazy Learning 알고리즘

# ■ Decision Tree - 의사결정나무

* 특정 기준(질문)에 따라 데이터를 구분하는 모델
* 한 번의 분기 때마다 변수 영역을 두 개로 구분하는 방식으로 구성 가능

※ 의사결정나무 - Node 분할

- 엔트로피 : 데이터 세트의 무질서도를 측정
- 정보이득 : 특성이 결과에 대한 엔트로피를 얼마나 감소시키는지를 나타냄
- 정보이득이 큰 방향으로 노드 분할

○ 엔트로피(Entropy)

- 데이터의 불확실성을 측정하는 지표
- 엔트로피 값이 클수록 데이터가 혼합되어 있음
- 엔트로피가 낮을수록 데이터가 더 순수하게 분류되어 있음

○ 정보이득(Information Gain)

- 노드를 분할한 후 데이터의 엔트로피가 얼마나 줄어드는지를 나타내는 지표
- 정보이득이 클수록 분할 후 데이터가 더 순수해진다는 의미
- 정보이득이 큰 특성은 더 유용한 정보를 제공한다고 판단하여 선택
