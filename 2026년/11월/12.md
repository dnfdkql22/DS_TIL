# 상관관계 분석 (Correlation Analysis)

## 1. 상관관계 분석

### ○ 상관관계 분석
- 두 변수 사이의 **관계의 방향과 강도**를 파악하는 통계 기법
- 상관계수(Correlation Coefficient) : 두 변수 사이의 상관관계 방향과 강도를 나타내는 수치

### ○ 상관관계의 종류
- **양의 상관관계(Positive Correlation)** : 변수 X가 커질수록 변수 Y도 커지는 경향
- **음의 상관관계(Negative Correlation)** : 변수 X가 커질수록 변수 Y는 작아지는 경향
- **상관관계가 거의 없음(No Correlation)** : 두 변수 사이에 뚜렷한 선형적 관계가 나타나지 않는 상태

※ 상관관계가 없다는 것은 두 변수 사이에 모든 종류의 관계가 없다는 의미가 아님. 비선형 관계가 존재할 수도 있음.

## 2. 분산과 공분산

### ○ 분산(Variance)
- 하나의 확률변수가 평균(기댓값)으로부터 얼마나 떨어져 있는지 나타내는 값
- 개별 데이터가 평균을 중심으로 얼마나 퍼져 있는지 측정
- 분산이 클수록 데이터의 흩어진 정도가 큼.

### ○ 공분산(Covariance)
- 두 확률변수(X, Y)가 각각의 평균으로부터 얼마나 떨어져 있으며, 함께 어떤 방향으로 변하는지 나타내는 값
- 두 변수 사이의 선형적인 동반 변동 방향을 측정

**공분산의 종류**
- **양의 공분산** : X가 평균보다 커질 때 Y도 평균보다 커지는 경향
- **음의 공분산** : X가 평균보다 커질 때 Y는 평균보다 작아지는 경향
- **0에 가까운 공분산** : 두 변수 사이의 선형적인 동반 변동이 거의 없음.

※ 공분산의 부호는 관계의 방향을 나타냄.

※ 공분산의 절댓값은 두 변수의 단위와 데이터의 퍼짐 정도에 영향을 받으므로, 절댓값만으로 서로 다른 변수 쌍의 관계 강도를 직접 비교하기 어려움.

### ○ 분산 vs 공분산

| 구분 | 분산 | 공분산 |
|---|---|---|
| 대상 | 하나의 변수 | 두 개의 변수 |
| 측정 | 데이터의 퍼짐 정도 | 두 변수가 함께 변하는 방향 |
| 양수 | 항상 0 이상 | 양수 또는 음수 |
| 활용 | 개별 변수의 변동성 파악 | 변수 간 동반 변동 파악 |

## 3. 상관계수 (Correlation Coefficient)

### ○ 피어슨 상관계수 (Pearson Correlation Coefficient)

- 두 변수 간의 **선형 관계의 방향과 강도**를 측정하는 척도
- 공분산을 두 변수의 표준편차의 곱으로 나누어 계산
- 공분산에서 데이터의 단위와 스케일 영향을 제거하여 비교하기 쉽게 만든 값

**계산 공식**

\[
r = \frac{Cov(X,Y)}{\sigma_X \times \sigma_Y}
\]

- \(Cov(X,Y)\) : X와 Y의 공분산
- \(\sigma_X\) : X의 표준편차
- \(\sigma_Y\) : Y의 표준편차
- \(r\) : 피어슨 상관계수

**피어슨 상관계수의 범위와 의미**

| 상관계수(r) | 의미 |
|---|---|
| r = +1 | 완벽한 양의 선형관계 |
| r = 0 | 선형관계 없음 |
| r = -1 | 완벽한 음의 선형관계 |

※ 상관계수는 -1부터 +1까지의 값을 가짐.

※ 상관계수의 부호는 관계의 방향, 절댓값은 선형관계의 강도를 나타냄.

### ○ 상관계수의 일반적인 해석 기준

| 상관계수(r) | 관계의 정도 |
|---|---|
| -1.0 ~ -0.7 | 강한 음의 선형관계 |
| -0.7 ~ -0.3 | 뚜렷한 음의 선형관계 |
| -0.3 ~ -0.1 | 약한 음의 선형관계 |
| -0.1 ~ 0.1 | 거의 무시할 수 있는 선형관계 |
| 0.1 ~ 0.3 | 약한 양의 선형관계 |
| 0.3 ~ 0.7 | 뚜렷한 양의 선형관계 |
| 0.7 ~ 1.0 | 강한 양의 선형관계 |

※ 위 기준은 일반적인 참고 기준이며, 연구 분야와 분석 목적에 따라 해석 기준이 달라질 수 있음.

### ○ 다른 상관계수 해석 기준

| 피어슨 상관계수 절댓값 | 상관관계 정도 |
|---|---|
| 0.9 이상 | 매우 높은 상관관계 |
| 0.7 ~ 0.9 | 높은 상관관계 |
| 0.4 ~ 0.7 | 다소 높은 상관관계 |
| 0.2 ~ 0.4 | 낮은 상관관계 |
| 0.2 미만 | 매우 낮은 상관관계 |

※ 두 표는 서로 다른 경험적 해석 기준이며, 절대적인 통계 법칙은 아님.

## 4. 상관분석의 종류

### ○ 피어슨 상관분석 (Pearson Correlation)
- 두 수치형 변수 사이의 선형관계 방향과 강도를 측정
- 가장 일반적으로 사용하는 상관분석 방법
- 이상치에 민감하며, 선형관계가 아닌 경우 관계를 제대로 반영하지 못할 수 있음.

### ○ 스피어만 상관분석 (Spearman Correlation)
- 데이터의 실제 값이 아닌 순위(Rank)를 이용하여 상관관계를 측정
- 두 변수 사이의 단조관계 방향과 강도를 측정
- 이상치나 정규분포 가정에 비교적 덜 민감함.
- 서열형 데이터에도 활용 가능

### ○ 켄달 상관분석 (Kendall Correlation)
- 관측값 쌍의 순서가 일치하는 정도를 이용하는 순위 상관계수
- 두 변수 사이의 순위 관계를 측정
- 표본 크기가 작거나 동점(Tie)이 많은 서열형 데이터에서 유용하게 활용 가능

### ○ 피어슨 vs 스피어만 vs 켄달

| 구분 | 피어슨 | 스피어만 | 켄달 |
|---|---|---|---|
| 측정 기준 | 실제 데이터 값 | 데이터 순위 | 관측값 쌍의 순서 |
| 관계 유형 | 선형관계 | 단조관계 | 단조적인 순위 관계 |
| 이상치 영향 | 민감함 | 상대적으로 덜 민감 | 상대적으로 덜 민감 |
| 주요 활용 | 연속형 수치 데이터 | 순위 및 연속형 데이터 | 소표본 및 서열형 데이터 |

### ○ 단조관계 (Monotonic Relationship)
- 한 변수가 증가할 때 다른 변수도 지속적으로 증가하거나 감소하는 관계
- 반드시 직선 형태일 필요는 없음.

**종류**
- 단조증가(Monotonically Increasing) : X가 증가할수록 Y도 증가하는 관계
- 단조감소(Monotonically Decreasing) : X가 증가할수록 Y는 감소하는 관계

※ 피어슨은 선형관계를 측정하고, 스피어만은 선형 여부와 관계없이 단조관계를 측정함.

## 5. 상관분석 vs 회귀분석

### ○ 상관계수 (Correlation Coefficient)
- 두 변수 사이의 선형관계 방향과 강도를 측정
- X와 Y의 순서를 바꾸어도 상관계수는 동일함.
- 두 변수 사이의 연관성을 파악하는 데 목적이 있음.

### ○ 회귀계수 (Regression Coefficient)
- 독립변수(X)가 종속변수(Y)에 미치는 영향의 크기와 방향을 나타내는 계수
- 다른 조건이 일정할 때 독립변수가 한 단위 증가하면 종속변수의 예측값이 평균적으로 얼마나 변하는지 나타냄.

### ○ 상관분석 vs 회귀분석 비교

| 구분 | 상관분석 | 회귀분석 |
|---|---|---|
| 역할 | 두 변수가 얼마나 함께 변하는가? | X를 통해 Y를 어떻게 설명하거나 예측하는가? |
| 변수 | X와 Y를 대칭적으로 취급 | 독립변수 X와 종속변수 Y 구분 |
| 결과 | 상관계수 | 회귀식, 회귀계수, 예측값 |
| 변수 순서 | X와 Y를 바꾸어도 동일 | X와 Y를 바꾸면 모형이 달라짐 |
| 인과관계 | 입증하지 못함 | 회귀분석만으로 입증할 수 없음 |
| 목적 | 관계의 방향과 강도 파악 | 관계의 모형화 및 예측 |

### ○ 결정계수 (Coefficient of Determination, R²)
- 회귀모형이 종속변수의 변동성을 얼마나 설명하는지 나타내는 지표
- 일반적인 최소제곱법의 절편 포함 OLS 회귀모형에서는 0~1 사이의 값을 가짐.
- 값이 클수록 해당 데이터에서 모형이 종속변수의 변동을 많이 설명함.

**예시**
- R² = 0.5
- 회귀모형이 종속변수의 관측된 변동 중 약 50%를 설명한다는 의미

※ 결정계수가 높다고 반드시 예측 성능이 우수하거나 인과관계가 성립하는 것은 아님.

※ 결정계수의 적절한 수준은 연구 분야와 분석 목적에 따라 달라짐.

## 6. 분산 → 공분산 → 상관 → 회귀

| 구분 | 핵심 질문 | 목적 |
|---|---|---|
| 분산 | 하나의 변수는 얼마나 퍼져 있는가? | 개별 변수의 변동성 파악 |
| 공분산 | 두 변수는 어떤 방향으로 함께 변하는가? | 변수 간 동반 변동 파악 |
| 상관 | 두 변수는 얼마나 강하게 함께 변하는가? | 관계의 방향과 강도 파악 |
| 회귀 | X를 통해 Y를 설명하거나 예측할 수 있는가? | 관계의 모형화 및 예측 |

### ○ 분석의 흐름
1. **분산** : 개별 데이터가 평균으로부터 얼마나 퍼져 있는지 확인
2. **공분산** : 두 변수가 함께 증가하거나 감소하는 방향 확인
3. **상관** : 공분산을 표준화하여 관계의 방향과 강도를 비교
4. **회귀** : 변수 사이의 관계를 수식으로 표현하여 설명 및 예측

※ 회귀분석에서는 직선뿐 아니라 곡선 형태의 비선형 관계도 모델링할 수 있음.

## 7. 선형과 비선형

### ○ 선형 (Linear)
- 그래프가 직선 형태로 표현되는 관계
- 일반적인 1차 함수 형태

\[
f(x)=ax+b
\]

### ○ 비선형 (Nonlinear)
- 그래프가 직선이 아닌 곡선 등의 형태로 표현되는 관계
- 변수 사이의 관계가 하나의 직선으로 표현되지 않는 경우

---

## 8. 신경망에서 선형 활성화 함수의 한계

### ○ 선형 활성화 함수 사용 시
- 신경망의 각 층이 입력에 대한 선형 변환만 수행
- 여러 층을 쌓아도 전체 네트워크는 하나의 선형 변환으로 표현 가능
- 따라서 은닉층을 여러 개 쌓더라도 복잡한 비선형 패턴을 학습할 수 없음.

### ○ 1층 선형 변환

\[
f(x)=ax+b
\]

### ○ 2층 선형 변환

\[
f(f(x))=a(ax+b)+b
\]

\[
=a^2x+ab+b
\]

### ○ 핵심 원리
- 선형 변환을 여러 번 결합해도 결과는 다시 선형 변환으로 표현됨.
- 따라서 층을 아무리 많이 쌓아도 하나의 선형 함수로 축약 가능
- 신경망이 복잡한 데이터 패턴을 학습하려면 비선형 활성화 함수가 필요함.

**대표적인 비선형 활성화 함수**
- ReLU : 음수는 0, 양수는 그대로 출력
- Sigmoid : 출력을 0~1 사이로 변환
- Tanh : 출력을 -1~1 사이로 변환

※ 활성화 함수에 비선형성을 적용해야 신경망이 복잡한 비선형 관계를 학습할 수 있음.
