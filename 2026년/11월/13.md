
# Sampling & Scaling

## 1. Sampling (표본 추출)

- 전체 모집단(Population)에서 조사 및 분석할 일부 대상을 선택하여 표본(Sample)을 구성하는 과정
- 모집단 전체를 조사하지 않고 표본을 이용하여 모집단의 특성을 추정하는 방법
- 적절하게 설계한 표본을 이용하여 모집단의 평균, 비율 등을 추정
- 표본 추출에 따른 오차와 편향 가능성을 고려해야 함
- 모집단을 정확하게 추론하기 위해서는 표본의 대표성을 고려한 추출방법 설계가 중요

### 1-1. 샘플링이 필요한 이유

**1. 시간 및 비용 제약 극복**
- 모집단 전체를 조사하는 전수조사는 시간과 비용이 많이 소요됨
- 데이터 샘플링을 통해 일부 데이터만 추출하여 조사 및 분석에 필요한 시간과 비용 절약

**2. 효율적인 인사이트 도출**
- 머신러닝 모델 학습 및 탐색적 데이터 분석(EDA)에서 데이터가 너무 크면 연산속도가 느려질 수 있음
- 샘플링을 통해 데이터 크기를 줄여 분석 및 모델 학습 효율 향상

**3. 분석 효율성 향상**
- 분석 목적에 적합한 데이터를 선택하여 불필요한 데이터 처리 부담 감소
- 단, 샘플링 자체가 Noise나 데이터 오류를 제거하는 것은 아니며, 데이터 정제는 별도의 전처리 과정이 필요

### 1-2. 샘플링의 종류

| 구분 | 영문명 | 설명 |
|---|---|---|
| 단순 임의 추출 | Simple Random Sampling | 모집단의 모든 개체가 동일한 확률로 선택되도록 무작위 추출 |
| 계통 추출 | Systematic Sampling | 첫 번째 표본을 무작위로 선택한 후 일정한 간격으로 추출 |
| 층화 임의 추출 | Stratified Random Sampling | 모집단을 여러 계층으로 나눈 후 각 계층에서 무작위 추출 |
| 군집 추출 | Cluster Sampling | 모집단을 여러 군집으로 나눈 후 일부 군집을 선택하여 조사 |
| 다단계 추출 | Multi-stage Sampling | 여러 단계에 걸쳐 순차적으로 표본을 추출 |

### 1-3. 주요 샘플링 기법

**1. 단순 무작위 샘플링 (Simple Random Sampling)**

- 모집단에서 임의로 표본을 선택하는 가장 기본적인 방법
- 모집단의 크기가 N인 경우, 크기가 n인 모든 가능한 표본이 동일한 확률로 추출되도록 하는 방법
- 복원 추출과 비복원 추출로 구분

| 구분 | 설명 |
|---|---|
| 복원 추출 | 한 번 뽑은 표본을 다시 모집단에 넣고 추출하는 방식으로 중복 선택 가능 |
| 비복원 추출 | 한 번 뽑은 표본을 다시 넣지 않고 추출하는 방식으로 중복 선택 불가능 |

**2. 계통 샘플링 (Systematic Sampling)**

- 첫 번째 표본을 무작위로 선택한 후 일정한 추출 간격에 따라 표본을 선택하는 방법
- 추출 간격은 일반적으로 모집단 크기를 표본 크기로 나누어 결정
- 모집단에 일정한 주기성이 존재하고 추출 간격과 겹치는 경우 특정 대상만 선택될 위험이 있음

예시)
- 제품 출시 후 고객 만족도 조사
- 일정한 간격으로 고객 명단에서 조사 대상 선택

**3. 층화 샘플링 (Stratified Sampling)**

- 모집단을 비슷한 특성을 가진 여러 층(Stratum)으로 나눈 후 각 층에서 단순 무작위 샘플링을 수행하는 방법
- 각 계층의 특성을 표본에 반영할 수 있음
- 계층별 비율에 따라 표본을 추출하거나 동일한 수의 표본을 추출할 수 있음

예시)
- 성별, 연령, 지역별로 모집단을 구분한 후 각 그룹에서 표본 추출

**4. 군집 샘플링 (Cluster Sampling)**

- 모집단을 여러 군집(Cluster)으로 나눈 후 일부 군집을 무작위로 선택하여 조사하는 방법
- 선택된 군집의 모든 구성원을 조사하거나, 군집 내부에서 다시 표본을 추출할 수 있음
- 샘플링 프레임을 개별 구성원 단위로 확보하기 어려운 경우 유용
- 일반적으로 각 군집 내부는 모집단의 다양한 특성을 포함하고, 군집 간에는 유사한 구성이 되도록 설계하는 것이 바람직함

예시)
- 전국 학교 중 일부 학교를 무작위로 선택한 후 해당 학교의 학생 조사

**5. 다단계 샘플링 (Multi-stage Sampling)**

- 여러 단계를 거쳐 순차적으로 표본을 추출하는 방법
- 군집 추출과 단순 무작위 추출 등을 조합하여 사용할 수 있음

예시)
- 1단계: 지역 선택
- 2단계: 지역 내 학교 선택
- 3단계: 학교 내 학급 선택
- 4단계: 학급 내 학생 선택

### 1-4. 확률적 샘플링과 비확률적 샘플링

**1. 확률적 샘플링 (Probability Sampling)**

- 모집단의 각 개체가 표본으로 선택될 확률을 알 수 있는 샘플링 방법
- 무작위 추출을 기반으로 하며 표본의 대표성을 확보하는 데 유리
- 표본 추출 확률을 알 수 있으므로 표본 오차 추정이 가능

주요 기법
- 단순 무작위 샘플링
- 계통 샘플링
- 층화 샘플링
- 군집 샘플링
- 다단계 샘플링

**2. 비확률적 샘플링 (Non-probability Sampling)**

- 특정 개체가 표본에 포함될 확률을 정확하게 알 수 없는 샘플링 방법
- 시간, 비용, 데이터 접근성 등의 제약이 있을 때 사용
- 표본의 대표성을 보장하기 어려우며 모집단에 대한 통계적 추론에 주의 필요

| 기법 | 설명 |
|---|---|
| 편의 샘플링 (Convenience Sampling) | 접근하기 쉽거나 조사하기 편리한 대상을 선택 |
| 판단 샘플링 (Judgment Sampling) | 연구자의 판단에 따라 특정 기준을 충족하는 대상을 선택 |
| 목적 샘플링 (Purposive Sampling) | 연구 목적에 적합한 특성을 가진 대상을 의도적으로 선택 |
| 눈덩이 샘플링 (Snowball Sampling) | 초기 표본 구성원이 다른 조사 대상자를 추천하는 방식으로 표본 확장 |

### 1-5. 부트스트랩 (Bootstrap)

- 관측한 표본 데이터에서 복원 추출을 반복하여 여러 개의 재표본(Resample)을 만드는 방법
- 각 재표본에서 통계량을 계산하여 통계량의 변동성 및 불확실성을 추정
- 평균, 중앙값, 신뢰구간 등의 통계적 특성을 추정하는 데 활용

**복원 추출을 사용하는 이유**
- 동일한 데이터가 여러 번 선택될 수 있도록 하여 다양한 재표본을 구성
- 원본 표본의 크기를 유지하면서 통계량의 변동성을 확인할 수 있음

### 1-6. 앙상블 부트스트랩 샘플링

- 앙상블 학습 기법 중 배깅(Bagging)에서 사용하는 샘플링 전략
- 원본 학습 데이터셋에서 복원 추출을 통해 여러 개의 서브 데이터셋을 생성
- 각 서브 데이터셋으로 개별 모델을 학습하여 모델 간 다양성 확보

**배깅 (Bagging)**

- Bootstrap Aggregating의 약자
- 여러 개의 모델을 결합하여 예측 성능과 안정성을 높이는 앙상블 학습 기법
- 부트스트랩으로 여러 학습 데이터셋을 생성하고, 각각의 모델을 학습시킨 후 예측 결과를 결합

처리 과정
1. 원본 데이터셋에서 복원 추출
2. 여러 개의 학습용 서브 데이터셋 생성
3. 각 데이터셋으로 개별 모델 학습
4. 개별 모델의 예측 결과 결합(Aggregating)

### 1-7. 샘플링 기법의 선택 기준

**1. 데이터의 특성과 분포**

- 데이터 크기와 복잡성
  - 대규모 데이터는 계산 비용을 줄이고 분석 효율을 높이기 위해 샘플링 적용
- 데이터 분포
  - 데이터에 편향이 있는 경우 층화 샘플링 등을 활용하여 각 범주의 특성을 반영
- 클래스 불균형
  - 특정 클래스에 데이터가 집중되어 있는 경우 오버샘플링(Over-sampling) 또는 언더샘플링(Under-sampling) 고려

**2. 연구 목적 및 모델 요구사항**

- 정확도와 효율성
  - 높은 정확도가 필요한 경우 표본의 대표성을 충분히 확보해야 함
  - 빠른 프로토타이핑이 목적이라면 간단한 샘플링 방법 활용 가능
- 모델의 종류
  - 머신러닝 모델의 특성에 따라 적합한 샘플링 전략 선택
  - 클래스 불균형에 민감한 모델은 별도의 불균형 데이터 처리 방법 고려

**3. 실행 시간 및 리소스 제약**

- 제한된 CPU, GPU, 메모리 등의 계산 자원을 고려
- 효율적인 샘플링을 통해 데이터 크기를 줄이고 모델 학습시간 단축
- 적절한 샘플링으로 메모리 사용량 및 연산 부담 감소

**4. 샘플링 편향 방지**

- 표본이 모집단의 특성을 충분히 반영하도록 대표성 유지
- 특정 그룹에 편중된 표본을 사용하면 모델의 일반화 성능이 저하될 수 있음
- 표본의 크기가 크더라도 추출 과정에서 편향이 발생하면 모집단을 정확하게 대표하기 어려움

**5. 재현성 및 검증**

- 샘플링 과정의 재현성을 위해 고정된 시드값(Random Seed) 사용
- 샘플링 방법과 추출 조건을 명확하게 문서화
- 교차검증(Cross Validation)을 활용하여 모델 성능 평가
- 데이터 누수(Data Leakage)가 발생하지 않도록 학습 데이터와 평가 데이터의 분리 및 샘플링 순서에 주의

### 1-8. 빅데이터 시대의 샘플링

- 데이터가 많아도 시간, 비용, 계산 자원의 제약으로 인해 샘플링은 여전히 필요
- 표본의 크기가 커지면 일반적으로 무작위 표본 오차를 줄이는 데 도움이 됨
- 잘못된 데이터 수집이나 표본 추출 과정에서 발생한 편향은 표본의 크기가 커져도 자동으로 사라지지 않음
- 데이터의 양뿐 아니라 표본의 대표성과 추출 과정의 적절성이 중요

## 2. Scaling (스케일링)

- 데이터의 수치적 크기와 범위를 일정한 기준에 맞게 조정하는 전처리 과정
- 특성(Feature)마다 서로 다른 범위와 단위를 가지는 경우 이를 조정하여 모델 학습에 미치는 영향을 줄이는 방법
- 특성 간 수치적 크기 차이가 모델 성능이나 학습 과정에 영향을 주지 않도록 조정
- 주로 선형 모델, SVM, 신경망 등 특성의 크기와 분포에 영향을 받는 모델에서 활용

### 2-1. 스케일링이 필요한 이유

**1. 특성 간 단위 차이 조정**
- 데이터마다 측정 단위와 값의 범위가 다를 수 있음
- 예시: 나이(20~60), 연봉(2,000만~1억), 키(150~190)
- 값의 범위가 큰 특성이 모델 학습에 과도한 영향을 미치는 것을 방지

**2. 모델 학습의 안정성과 효율성 향상**
- 특성의 범위를 조정하여 모델의 학습 안정성과 수렴 속도 개선
- 거리 기반 알고리즘에서 특정 특성이 거리 계산에 과도하게 반영되는 문제 완화

**3. 특성 간 비교 용이성**
- 서로 다른 척도를 일정한 기준으로 조정하여 특성 간 수치 비교를 용이하게 함
- 각 특성의 중요도나 가중치를 결정하는 과정과는 별개

### 2-2. 주요 스케일링 기법

**1. 표준화 (Standardization)**

- 각 Feature의 평균을 0, 표준편차를 1로 변환하는 방법
- 평균과 표준편차를 기준으로 데이터의 분포를 조정
- 이상치가 평균과 표준편차에 영향을 주기 때문에 이상치에 상대적으로 민감

수식

Z = (X - 평균) / 표준편차

특징
- 평균 = 0
- 표준편차 = 1
- SVM, 로지스틱 회귀, 선형 모델, 신경망 등에 활용

파이썬 코드
```python
from sklearn.preprocessing import StandardScaler

ss = StandardScaler()

x_train_s = ss.fit_transform(x_train)
x_test_s = ss.transform(x_test)
```

**2. 정규화 / 최소-최대 스케일링 (Min-Max Scaling)**

- 데이터의 최솟값을 0, 최댓값을 1로 변환하여 일반적으로 0~1 범위로 조정
- 데이터의 기존 분포 형태를 유지하면서 값의 범위를 조정
- 이상치가 존재하면 대부분의 데이터가 좁은 범위로 압축될 수 있음

수식

X_scaled = (X - X_min) / (X_max - X_min)

특징
- 데이터 범위: 0~1
- 이미지 데이터 및 신경망 등에 활용
- 이상치에 민감

파이썬 코드
```python
from sklearn.preprocessing import MinMaxScaler

mms = MinMaxScaler()

x_train_s = mms.fit_transform(x_train)
x_test_s = mms.transform(x_test)
```

**3. 로버스트 스케일링 (Robust Scaling)**

- 중앙값(Median)과 사분위 범위(IQR)를 사용하여 데이터를 변환하는 방법
- 이상치의 영향을 상대적으로 적게 받음
- 이상치가 많은 데이터에 적합

수식

X_scaled = (X - Median) / IQR

IQR = Q3 - Q1

특징
- 중앙값을 기준으로 데이터 중심 조정
- IQR을 기준으로 데이터 범위 조정
- 이상치에 상대적으로 덜 민감

파이썬 코드
```python
from sklearn.preprocessing import RobustScaler

rs = RobustScaler()

x_train_s = rs.fit_transform(x_train)
x_test_s = rs.transform(x_test)
```

**4. 벡터 정규화 (Vector Normalization)**

- 각 데이터 포인트(샘플)의 특징 벡터 크기를 1로 변환하는 방법
- 원점으로부터의 거리를 1로 조정
- 각 샘플의 방향은 유지하면서 벡터의 크기를 조정
- 자연어 처리(NLP), 텍스트 마이닝 등에서 활용

특징
- Feature별 범위를 조정하는 방식이 아니라 Sample별 벡터의 크기를 조정
- 일반적으로 L1 또는 L2 Norm을 사용

파이썬 코드
```python
from sklearn.preprocessing import Normalizer

norm = Normalizer()

x_train_s = norm.fit_transform(x_train)
x_test_s = norm.transform(x_test)
```

### 2-3. 스케일링 기법 비교

| 구분 | StandardScaler | MinMaxScaler | RobustScaler | Normalizer |
|---|---|---|---|---|
| 기준 | 평균, 표준편차 | 최솟값, 최댓값 | 중앙값, IQR | 벡터의 크기 |
| 변환 결과 | 평균 0, 표준편차 1 | 기본 0~1 | 중앙값 0, IQR 1 | 벡터 크기 1 |
| 이상치 민감도 | 높음 | 높음 | 낮음 | 이상치 자체를 처리하지 않음 |
| 적용 단위 | Feature별 | Feature별 | Feature별 | Sample별 |
| 주요 활용 | SVM, 회귀, 신경망 | 신경망, 이미지 데이터 | 이상치가 많은 데이터 | NLP, 텍스트 마이닝 |

### 2-4. 스케일링 적용 시 주의사항

**1. 학습 데이터와 테스트 데이터 분리**
- 학습 데이터(x_train)를 기준으로 스케일링 기준값을 계산
- 테스트 데이터(x_test)는 학습 데이터에서 계산한 기준값을 적용

**2. fit_transform()과 transform()의 차이**

| 메서드 | 역할 |
|---|---|
| fit() | 데이터의 평균, 표준편차, 최솟값 등 스케일링에 필요한 기준값 학습 |
| transform() | 학습한 기준값을 사용하여 데이터 변환 |
| fit_transform() | 기준값 학습과 데이터 변환을 동시에 수행 |

**3. 데이터 누수(Data Leakage) 방지**
- 전체 데이터를 대상으로 먼저 스케일링하면 테스트 데이터의 정보가 학습 과정에 반영될 수 있음
- 반드시 학습 데이터에서만 fit()을 수행하고 테스트 데이터에는 transform()만 적용
- 교차검증에서는 각 학습 Fold 내부에서 스케일링을 수행하는 Pipeline 사용 권장
