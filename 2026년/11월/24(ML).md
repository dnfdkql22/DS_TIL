# 머신러닝 정리: SVM · 군집화(K-means)

## Logistic Regression

### SVM : 클래스를 구분하면서, 경계 양쪽의 여유공간인 ‘마진’을 크게 확보하도록 학습하는 지도학습 모델

### 서포트 벡터 머신
- 지도 학습의 일종으로 분류 문제에 사용할 수 있는 강력하고 유연한 머신러닝 모델
- 분류SVM은 서로 다른 클래스를 구분하면서 마진을 크게 확보하는 결정 경계를 학습
- 선형 SVM은 입력공간에서 선형경계를 찾고, 커널 SVM은 원래 입력공간에서 비선형 경계도 표현
- 결정경계는 서포트 벡터라는 일부 훈련 데이터에 의해 결정

### SVM 주요 개념
- **서포트 벡터** : 결정 경계와 마진을 정하는 데 직접 영향을 주는 훈련 데이터 포인트
- **결정 경계** : 서로 다른 클래스를 분리하는 경계 / 선형SVM에서는 직선, 평면, 초평면으로 표현됨
- **마진** : 결정 경계 양쪽에 확보하려는 여유 폭

## Clustering(군집화)
> 정답(레이블)이 없는 데이터를 비슷한 특성끼리 자동으로 묶어 그룹을 만드는 비지도 학습 모델

### How
- data 매핑공간에서 거리 (d)가 가까운 데이터 들은 동일한 클러스터로 인식, 거리가 먼 데이터들은 서로 다른 클러스터로 분류

### k-means process
1. k : 클러스터 개수(사용자 설정)
2. centroid : 클러스터의 중심점 k개 설정
3. 각 클러스터 별 중심점과 가까운 데이터를 해당 클러스터로 배정
4. 새롭게 클러스터에 배정된 데이터를 포함한 새로운 centroid 설정
5. 더 이상의 centroid 갱신이 없을 때까지 3-4 반복

### 이슈

#### ※ 초기 k를 몇으로 선택할 것인가?
- 클러스터의 수에 따른 이너셔값
- **Elbow Method**
  - 이너셔 : 클러스터 내 데이터 포인트들과 클러스터 중심점 간 거리의 제곱 합 ⇒ 클러스터 응집도
  - 이너셔 값이 작을수록 클러스터 내 데이터 포인트 들이 중심에 더 가깝게 모여있음을 의미
- **silhouette Score**
  1. 데이터 A가 속한 클러스터 내의 다른 데이터들 a와의 거리 평균 계산
  2. 데이터 A와 다른 클러스터의 데이터들 b의 거리평균 계산
  3. 데이터 A와 다른 클러스터의 데이터들 c의 거리평균 계산
  4. 데이터 A의 silhouette Score : $s = \dfrac{b - a}{\max(a, b)}$
  5. 모든 클러스터의 모든 데이터들에 대한 silhouette Score를 계산 후 평균 산출
  6. silhouette Score 평균이 1에 가까운 K를 최적의 K로 설정

  - 0에 가까운 경우 : 두 군집 간 거리가 비슷한 상황 → 잘 구분되지 않은 상태
  - 1에 가까운 경우 : 잘 분리된 클러스터
  - 적절한 클러스터 개수를 정하거나 더 나은 클러스터링 기법을 선택하는 기준으로 활용가능
  - 클러스터링 결과 값 시각화 가능
  - 데이터 셋 크기에 비례하여 계산시간 증가

#### ※ 시작 centroid 위치를 어디로 할 것인가?
- **Random Select(랜덤 초기화)**
  - 초기 중심점(Centroid)를 무작위로(Random) 선택
  - 간단하고 빠르게 초기 중심점을 설정할 수 있다.
  - 무작위 선택으로 인해 최종 클러스터링 결과가 불안정 할 수도 있다.
- **K-means++** : 초기 중심점이 서로 멀리 떨어져 있도록 선택 → 클러스터링 결과가 더 안정적, 더 좋은 성능
  - 첫 번째 중심점을 무작위로 선택
  - 그 이후의 중심점은 기존에 선택된 중심점 들로부터 가장 먼 데이터 포인트를 선택 배치
  - 클러스터 개수 k만큼 반복 과정 반복

| 항목 | Random Select | K-means++ |
| :--- | :--- | :--- |
| 중심점 선택 방식 | 무작위로 선택 | 기존 중심점에서 먼 데이터를 선택 |
| 속도 | 빠름 | 초기화 단계에서 다소 느림 |
| 결과 안정성 | 불안정, 로컬 최적화 가능성 있음 | 더 안정적, 더 좋은 클러스터링 가능 |
| 성능 | 초기화에 따라 다름 | 대부분의 경우 성능이 더 좋음 |
