# ■ EDA (Exploratory Data Analysis, 탐색적 데이터 분석)

## ○ 학습 목표
- 전체 데이터 분석 프로세스에서 EDA의 역할 이해
- 적절한 단변량 및 다변량 분석 수행

## ○ EDA란?
- 데이터를 심층적으로 이해하고 주요 특징을 요약, 시각화, 통계적 분석을 통해 숨겨진 패턴과 관계성을 발견하는 과정
- 데이터 분석 및 모델링을 수행하기 전에 데이터의 특성과 품질을 파악하는 단계

### * EDA의 목적

- 데이터 이해
  - 데이터의 구조, 변수 유형, 분포, 통계적 특성(평균, 중앙값, 표준편차 등) 파악

- 패턴 및 관계 발견
  - 변수들 간의 숨겨진 관계와 패턴 식별

- 문제점 식별
  - 결측값, 이상치, 데이터 불일치 등 데이터 품질 문제 발견 및 처리방법 결정

- 가설 생성 및 검증
  - 데이터를 바탕으로 의미 있는 가설 수립 또는 기존 가정 검토

- 최적의 분석 기법 선택
  - 데이터 특성을 이해하여 분석 목적과 데이터에 적합한 통계 기법 및 머신러닝 모델 선택

### * 데이터 구조와 의미 파악

- 한 행(Row)은 무엇을 의미하는가?
- 각 열(Column)은 무엇을 측정하는가?
- 행과 열의 개수, 변수 설명, 자료형, 측정 단위, 수집 기간 확인

### * 데이터 품질 확인

- 누락되거나 중복된 값, 잘못 기록된 값이 있는가?
- 결측치 비율, 중복 행, 범위 및 형식 오류 확인

### * 변수 분포 탐색

- 값이 어디에 몰려 있는가? 얼마나 흩어져 있는가?
- 평균, 중앙값, 표준편차, 분위수, 빈도표, 히스토그램 등을 활용

### * 이상치 탐색

- 일반적인 값들과 크게 다른 관측치는 무엇인가?
- 박스플롯, 산점도 등을 활용하고 해당 관측치의 발생 맥락 확인

### * 변수 간 관계 탐색

- 어떤 변수들이 함께 변화하는가?
- 산점도, 상관계수, 교차표 등을 활용

### * 집단별 비교

- 전체 데이터에서는 파악되지 않는 집단별 차이가 나타나는가?
- 집단별 건수, 평균, 중앙값, 비율 비교

### * 시간에 따른 변화 탐색

- 시간의 흐름에 따른 추세, 계절성, 갑작스러운 변화가 있는가?
- 시계열 그래프 및 기간별 통계량 비교

### * 발견 내용과 후속 질문 정리

- 무엇을 알게 되었으며, 무엇을 추가로 확인해야 하는가?
- 관찰 사실, 가설, 분석의 한계, 추가 데이터 수집 필요성 정리


## ○ EDA in CRISP-DM

### * Business Understanding (비즈니스 이해)
- 초기 가설 수립 및 측정 기준 정의
- 목표 및 성공 지표 정의
  - 분석 목표와 데이터의 양, 품질, 레이블 유무 등 검토
- KPI 및 타깃 정의
  - 데이터로 측정하거나 예측할 수 있는 목표인지 검토
- Feasibility Check (실현 가능성 검토)
  - 현재 데이터와 자원으로 분석 목표를 달성할 수 있는지 검토

### * Data Understanding (데이터 이해)
- Explore Data (데이터 탐색)
- Verify Data Quality (데이터 품질 검증)
- 데이터의 의미와 구조 이해
  - 변수의 의미, 단위, 범위 파악
- 데이터 분포, 패턴, 관계 파악
  - 단변량 및 다변량 분석 수행
- 데이터 품질 문제 발견
  - 결측치, 이상치, 오류, 중복 등 확인

### * Data Preparation (데이터 준비)
- 데이터 전처리 수행
- 전처리 후 데이터 검증
- 전처리 전후의 데이터 분포 및 특성 변화 확인

### * Modeling (모델링)
- 모델 학습 및 성능 평가
- 중요 피처(Feature) 해석
- 모델의 예측 결과와 데이터 특성 비교

### * Evaluation (평가)
- 분석 결과가 비즈니스 목표를 충족하는지 평가
- 모델 성능 및 분석 결과의 적절성 검증

### * Deployment (배포)
- 분석 모델 및 결과를 실제 서비스에 적용
- 배포 후 서비스 데이터의 분포와 품질 변화 확인
- 데이터 분포 변화(Data Drift) 및 모델 성능 저하 모니터링


## ○ EDA - Overview & Practice

### * 기본 통계 분석
- 데이터 크기, 자료형, 기초 통계량 확인
- 결측값 및 중복 데이터 확인

### * 데이터 시각화
- 히스토그램, 박스플롯, 산점도, 상관관계 히트맵

### * 이상치 탐색
- 박스플롯, IQR, Z-Score 활용

### * 변수 간 관계 분석
- 상관관계 및 공분산 분석
- 산점도 및 교차표 활용

### * 결측값 처리
- 평균, 중앙값, 최빈값 등을 활용한 대체
- 결측 행 또는 열 삭제
- 결측 패턴을 고려한 처리

### * 데이터 변환
- 정규화(Normalization)
- 표준화(Standardization)
- 로그 변환(Log Transformation)
- 범주형 변수 인코딩(Encoding)


## ○ 단변량 분석과 다변량 분석

| 구분 | 단변량 분석 | 다변량 분석 |
|---|---|---|
| 분석 대상 | 하나의 변수 | 두 개 이상의 변수 |
| 분석 목적 | 변수 자체의 특성 파악 | 변수 간 관계 및 상호작용 파악 |
| 주요 내용 | 분포, 평균, 중앙값, 이상치 | 상관관계, 집단별 차이, 변수 간 관계 |

### * 그래픽 방법 (Graphical Methods)

#### 단변량 분석

- 정량형 변수
  - 히스토그램(Histogram)
  - 상자그림(Box Plot)
  - 일반 Q-Q Plot

- 범주형 변수
  - 막대 차트(Bar Chart)

- 시간 데이터
  - 선 그래프(Line Plot)

#### 다변량 분석

- 하나의 범주형 변수 + 하나의 양적 변수
  - 나란히 상자그림(Side-by-Side Box Plot)

- 둘 이상의 범주형 변수
  - 그룹화된 막대 차트(Grouped Bar Chart)
  - 누적 막대 차트(Stacked Bar Chart)

- 둘 이상의 정량형 변수
  - 산점도(Scatter Plot)
  - 상관관계 히트맵(Correlation Heatmap)
  - 쌍도표(Pair Plot)

- 누락된 데이터 감지
  - 결측치 분포 및 결측 패턴 시각화

### * 비그래픽 방법 (Non-Graphical Methods)

#### 단변량 분석

- 범주형 변수
  - 빈도(Frequency)
  - 상대 빈도(Relative Frequency)
  - 빈도표 및 비율표

- 정량형 변수
  - 위치(Location)
    - 평균(Mean), 중앙값(Median)
  - 산포(Spread)
    - IQR, 표준편차, 범위(Range)
  - 최빈값(Mode)
  - 분포의 모양(Shape)
    - 왜도(Skewness), 첨도(Kurtosis)
  - 이상치(Outlier)
  - 결측 데이터 확인

#### 다변량 분석

- 하나의 범주형 변수 + 하나의 양적 변수
  - 범주형 변수의 각 수준별로 양적 변수의 통계량 계산
  - 평균, 중앙값, 범위, 표준편차 등 비교

- 둘 이상의 정량형 변수
  - 상관관계(Correlation)
  - 공분산(Covariance)
  - 변수별 기술통계량 비교
  - 결측 데이터 패턴 확인

- 둘 이상의 범주형 변수
  - 교차표(Contingency Table)
  - 빈도 및 상대 빈도 비교


## ○ 단변량 분석 (Univariate Analysis)

- 하나의 변수에 집중하여 해당 변수의 특성과 분포를 파악하는 분석 방법

### * 범주형 데이터 (Categorical Data)

- 전체 데이터 건수
- 범주별 빈도(Frequency)
- 범주별 구성비율(Relative Frequency)
- 최빈 범주(Mode)

### * 수치형 데이터 (Numerical Data)

- 값의 범위
  - 최소값(Min), 최대값(Max)
  - 범위(Range)
  - 중앙값(Median)

- 분포의 모양
  - 좌우 대칭 또는 오른쪽·왼쪽 치우침
  - 왜도(Skewness), 첨도(Kurtosis)

- Outlier Detection
  - 이상치 탐색

- Missing Data
  - 결측치 존재 여부 및 비율 확인

### * 수치형 변수 분석 방법

- 그래픽 방법
  - 히스토그램, 박스플롯, Q-Q Plot 등
  - 분포, 중앙값, 범위, 이상치 등을 시각적으로 분석

- 비그래픽 방법
  - 평균, 중앙값, 최빈값, 분산, 표준편차 등
  - 변수의 특성을 통계량으로 파악

### * 범주형 변수 분석 방법

- 그래픽 방법
  - 막대그래프 등을 활용하여 각 범주의 빈도와 비율을 시각적으로 표현

- 비그래픽 방법
  - 각 범주의 빈도 및 상대 빈도를 표로 표현하여 범주별 특성 분석


## ○ 단변량 그래프

### * Q-Q Plot (Quantile-Quantile Plot)
- 데이터의 실제 분포와 이론적 분포의 분위수를 비교하는 시각적 도구
- 일반적으로 정규분포와 비교하여 데이터의 정규성을 확인
- 점들이 대각선에 가까울수록 이론적 분포와 유사함
- 대각선에서 크게 벗어날수록 정규분포와 차이가 있음을 의미

### * 분위수 비교 (Quantile Comparison)
- 데이터를 분위수로 나누어 분포의 특성을 파악
- 중앙값, 사분위수, 백분위수 등을 활용
- 데이터의 위치와 분포 형태 이해

### * 밀도 플롯 (Density Plot)
- 데이터의 전체적인 분포 형태를 연속적인 곡선으로 표현
- 데이터가 집중된 위치와 분포의 형태 확인
- 정규분포와 비교하여 정규성 평가에 참고 가능

### * 히스토그램 (Histogram)
- 데이터를 일정한 구간(Bin)으로 나누어 구간별 빈도를 막대로 표현
- 데이터의 분포, 치우침, 봉우리 개수 등을 확인

### * 박스플롯 (Box Plot)
- 중앙값, 사분위수, IQR 및 이상치를 시각적으로 표현
- 데이터의 산포와 이상치 확인


## ○ 정규성 검정 (Normality Test)

### * 통계적 정규성 검정
- 데이터가 정규분포를 따르는지 통계적으로 검정하는 방법

### * Shapiro-Wilk Test
- 대표적인 정규성 검정 방법
- 특히 소규모 표본에서 자주 활용

- 귀무가설(H0)
  - 데이터는 정규분포를 따른다.

- 대립가설(H1)
  - 데이터는 정규분포를 따르지 않는다.

- p-value < 0.05
  - 귀무가설 기각
  - 정규분포를 따른다고 보기 어려움

- p-value >= 0.05
  - 귀무가설 기각 불가
  - 정규분포를 따르지 않는다는 충분한 증거가 없음

※ 표본 크기가 매우 크면 작은 차이도 유의하게 나타날 수 있으므로 Q-Q Plot 등 시각적 분석을 함께 활용한다.


# ■ 데이터 전처리 (Data Pre-processing)

## ○ 데이터 무결성 (Data Integrity)

- 데이터 값이 정확하고 완전한 상태
- 데이터의 정확성, 일관성, 신뢰성을 유지하는 것
- 데이터가 손상되거나 임의로 변경되지 않고 올바르게 유지되는 상태
- 데이터 품질을 보장하기 위한 기본적인 개념

### * 주요 요소

- 정확성(Accuracy)
  - 실제 사실과 데이터 값이 일치하는 정도

- 완전성(Completeness)
  - 필요한 데이터가 누락되지 않은 정도

- 일관성(Consistency)
  - 서로 다른 데이터 간 모순이 없는 정도

- 유효성(Validity)
  - 사전에 정의된 규칙과 형식에 맞는 정도


## ○ 데이터 정합성 (Data Consistency)

- 여러 데이터가 서로 모순되지 않고 일관되게 일치하는 상태
- 동일한 대상에 대한 데이터가 여러 시스템이나 테이블에 걸쳐 동일한 기준으로 유지되는 것
- 데이터 간의 관계 및 값의 일치 여부를 확인하는 개념

※ 데이터 무결성과 정합성의 차이

- 무결성
  - 데이터 자체가 정확하고 완전하며 신뢰할 수 있는 상태인가?

- 정합성
  - 여러 데이터 간의 값과 관계가 서로 일치하고 모순되지 않는가?


## ○ Data Pre-processing (데이터 전처리)

- 정제되지 않은 원본 데이터를 분석 및 모델링에 적합한 형태로 만드는 과정
- 데이터의 오류, 결측치, 이상치 등을 처리하고 분석 목적에 맞게 변환하는 작업
- 데이터 분석 및 머신러닝 과정에서 중요한 단계

### * 데이터 전처리의 중요성 및 목적

#### 1. 정확한 분석 결과 도출
- 데이터는 수집 단계에서부터 오류, 결측치, 이상치, 불일치 등이 존재할 수 있음
- 잘못된 데이터를 그대로 사용하면 분석 결과의 신뢰성이 저하될 수 있음

#### 2. 모델 성능 향상
- 많은 머신러닝 모델은 적절하게 전처리된 데이터를 필요로 함
- 결측치, 이상치, 스케일 차이, 범주형 데이터 미처리 등은 모델 성능 저하 및 과적합 등의 문제를 유발할 수 있음
- 분석 기법에 적합한 형태로 데이터를 변환하여 학습 효율 향상

#### 3. 현실 반영 및 신뢰성 확보
- 데이터가 가진 현실적인 의미를 유지하고 해석 가능한 결과를 얻기 위한 작업
- 현업에서는 데이터 품질이 비즈니스 의사결정의 신뢰성과 직접적으로 연결됨

※ 핵심
- 모델 입력에 적합한 형태로 데이터를 정제하고 변형하는 작업


## ○ 데이터 전처리 기법

### * 기본적인 전처리

- 결측치 처리
  - 데이터에서 누락된 값이 있을 경우 대체하거나 삭제
  - 평균, 중앙값, 최빈값 등을 활용

- 이상치 처리
  - 일반적인 데이터 범위에서 크게 벗어난 값 처리
  - 삭제, 대체, 변환 또는 유지 여부 결정
  - 분석 결과에 미치는 영향을 고려

- 데이터 정규화(Normalization)
  - 서로 다른 스케일의 데이터를 일정한 범위로 조정

- 데이터 표준화(Standardization)
  - 데이터의 평균을 0, 표준편차를 1로 변환

- 데이터 인코딩(Encoding)
  - 비수치형 데이터를 컴퓨터가 처리할 수 있는 수치형 데이터로 변환

- 데이터 통합(Integration)
  - 여러 데이터 소스를 하나의 데이터로 통합

- 데이터 분할(Splitting)
  - 분석 및 모델 학습 목적에 따라 데이터를 여러 부분으로 분리

### * 데이터 핸들링 및 가공

- 데이터 정렬(Sorting)
  - 분석에 필요한 순서로 데이터 정렬
  - pandas: sort_values()

- 데이터 그룹화(Grouping)
  - 데이터를 그룹별로 분류하고 그룹별 통계 정보 추출
  - pandas: groupby()

- 데이터 변환 함수(Transformation)
  - 데이터 값을 목적에 맞게 변환
  - pandas: apply(), map(), replace()

- 데이터 피벗(Pivot)
  - 행과 열의 구조를 변경하거나 그룹별 집계 정보 표현
  - pandas: pivot(), pivot_table()

- 데이터 병합(Merging)
  - 여러 데이터프레임을 특정 기준에 따라 결합
  - pandas: merge(), concat()

- 데이터 샘플링(Sampling)
  - 전체 데이터에서 일부 표본을 추출
  - pandas: sample()

- 데이터 집계(Aggregation)
  - 그룹별 합계, 평균, 개수 등 통계 정보 추출
  - pandas: agg(), groupby()

- 데이터 시각화(Visualization)
  - 그래프를 통해 데이터의 특성과 패턴을 파악


## ○ 데이터 분류

### * 데이터 타입 (Data Type)
- 프로그래밍 언어에서 데이터의 자료형을 구분하는 개념
- int: 정수형
- float: 실수형
- str: 문자열
- bool: 불리언(참/거짓)

### * 데이터 속성 (Variable Type)
- 통계 및 머신러닝 분석 관점에서 변수의 특성을 구분하는 개념

- 범주형(Categorical)
  - 명목형(Nominal)
  - 순서형(Ordinal)

- 수치형(Numerical)
  - 이산형(Discrete)
  - 연속형(Continuous)

### * 데이터 유형 (Data Structure)
- 데이터의 구조화 정도에 따른 분류

- 정형 데이터(Structured Data)
  - 행과 열로 구성된 표 형태의 데이터
  - 예: 엑셀, 관계형 데이터베이스

- 반정형 데이터(Semi-structured Data)
  - 일정한 구조나 태그, 키-값 형식 등을 포함하지만 고정된 테이블 구조는 아님
  - 예: JSON, XML, HTML

- 비정형 데이터(Unstructured Data)
  - 고정된 구조 없이 다양한 형태로 존재하는 데이터
  - 예: 이미지, 영상, 음성, 텍스트 문서


## ○ 데이터 분할 (Data Splitting)

- 전체 데이터를 학습, 검증, 테스트 목적으로 나누는 과정
- 모델의 학습 및 평가 과정에서 데이터의 역할을 구분하기 위해 사용

### * Train Set (훈련 데이터)

- 모델을 학습시키는 데 사용되는 데이터
- 입력 데이터와 이에 대응하는 출력값(Label)을 학습하여 패턴을 찾아내는 과정에 사용
- 일반적으로 전체 데이터의 60~80%

### * Validation Set (검증 데이터)

- 모델의 성능 평가 및 하이퍼파라미터 조정에 사용
- 훈련 데이터로 학습한 모델이 새로운 데이터에서 얼마나 잘 예측하는지 확인
- 과적합(Overfitting) 여부 확인 및 모델 선택에 활용
- 일반적으로 전체 데이터의 10~20%

### * Test Set (테스트 데이터)

- 최종적인 모델 성능 평가에 사용
- 훈련 및 검증 과정에서 사용하지 않은 독립적인 데이터
- 모델의 일반화 성능을 평가
- 일반적으로 전체 데이터의 10~20%

### * 데이터 분할 시 주의사항

- 데이터 누수(Data Leakage) 방지
  - 테스트 데이터의 정보가 학습 과정에 포함되지 않도록 주의

- 전처리 순서
  - 훈련 데이터로 결측치 대체 기준, 스케일링 기준 등을 학습
  - 동일한 기준을 검증 및 테스트 데이터에 적용

- 데이터 불균형 고려
  - 분류 문제에서는 클래스 비율이 각 데이터 세트에 비슷하게 유지되도록 계층적 분할(Stratified Split) 고려

- 시계열 데이터
  - 시간 순서를 유지하여 과거 데이터를 훈련에 사용하고 미래 데이터를 평가에 사용
