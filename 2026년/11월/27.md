# 머신러닝 정리: 앙상블(Ensemble) · 배깅 · 부스팅 · 스태킹

## Ensemble
- **사전적 의미** : 2인 이상에 의한 가창이나 연주 / 주로 실내악을 연주하는 소인원의 합주단, 합창단

### 앙상블
- 여러 개의 기본 학습기라고 불리는, 다수의 예측 모델을 결합하여 단일 예측 모델보다 더 좋은 성능을 목표로 하는 모델링 과정
- 여러 개의 개별 모델을 조합하여 최적의 모델로 일반화하는 과정
- 복잡하고 다양한 데이터셋에 대해 더 정확한 예측을 제공하기 위해 개발

### 기본 학습기, 약한 학습기
- 개별 모델로는 데이터의 패턴을 완벽하게 학습하지 못할 수 있지만, 여러 개를 조합함으로써 강한 예측 성능을 낼 수 있는 모델
- 개별 모델이 약할지라도 여러 모델의 예측을 적절히 결합 → 성능 향상

#### 앙상블 효과
- 각 모델이 어느 정도의 성능을 내고 (Base Line보다는 좋게)
- 오차는 서로 다른 방식으로 틀려야 한다.

#### 앙상블의 다양성
- 구성 모델들이 서로 다른 예측 특성과 오류 패턴을 갖는 것
- 개별 모델의 예측 성능을 확보하면서, 서로의 오류를 보완하도록 해야 한다.

## Diversity of Base Learners : 앙상블 학습에서의 다양성

### 1. 학습 데이터와 샘플 가중치 변경
- 모델마다 서로 다른 학습 데이터를 사용하거나, 데이터의 중요도를 다르게 부여

### 2. 입력 특성 변경
- 모델마다 사용하는 특성이나, 분할 시 검토하는 특성을 다르게 구성
- → 모든 모델이 동일한 특성에만 의존하는 상황 완화

### 3. 학습 과정에 무작위성 부여
- 동일한 모델 구조라도 학습 과정이 달라지도록 구성
- 학습 과정의 무작위성이 모델 간 차이를 유도할 수 있음
- **but** 이러한 무작위성이 반드시 모델 성능을 높이거나 모델 예측 결과를 달라지게 하지는 않음

### 4. 모델 종류, 구조, 하이퍼파라미터 변경
- 서로 다른 학습 특성을 가진 모델들을 결합
- 같은 모델이라도 트리 깊이, 신경망 구조 등을 다르게 설정
- 결합 방법 : Voting, Stacking

## 앙상블 구분 : 기법별 다양성 확보 방법

### Bagging (Bootstrap Aggregating)
- 서로 다르게 추출한 데이터로 모델들을 학습
- 결합 : 예측을 평균/투표 등으로 집계
- **Bootstrap** : 원본 데이터에서 중복을 허용하며, 여러 학습 데이터셋을 만드는 방법
- **Aggregating** : 개별 모델들의 예측 결과를 평균(회귀) 또는 다수결(분류) 방식으로 결합

### Boosting
- 앞선 예측의 부족한 부분을 보완하도록 후속 모델 학습
- 결합 : 순차적으로 학습한 모델들의 예측 결합
- **Boost** : 강화하다라는 의미
- 약한 모델(Weak Learner)을 여러 개 연결하여 점점 더 강한 모델로 만듦

### Stacking
- 서로 다른 모델 종류/구조/설정으로 예측 패턴의 차이 확보
- 메타 모델이 예측의 결합 방법을 학습
- **Stack** : 쌓다
- 개별 모델(Base Learners)의 예측 결과를 새로운 입력 특성으로 사용 → 메타 모델에 입력
  - → 여러 개의 모델을 쌓아서 최종적인 예측 수행

### 배깅 : 분산 감소
- 서로 다른 부트스트랩 데이터로 학습한 모델들이, 동일한 입력에 대해 예측한 값
- 개별 모델의 예측이 서로 다름
- 예측을 평균하면 일부 모델의 지나치게 크거나 작은 예측이 완화됨
- 모델들의 오류가 완전히 같지 않다면 평균 예측은 개별 모델보다 학습 데이터 변화에 덜 흔들릴 수 있음 → **분산 감소 효과**

### 부스팅 : 편향 감소
- 현재 예측의 남은 오차를 목표값으로 학습 (학습할 목표값이 잔차임)
- 기존 모델이 낮게 또는 높게 예측한 부분을 다음 모델의 보정값을 더하여 개선
- → 단순한 모델이 놓친 패턴을 보완 → **편향 감소**

> ※ **잔차** : 정답과 기존 모델 예측의 남은 오차
>
> ※ 참고 : 잔차를 목표값으로 학습하는 방식은 Gradient Boosting의 방식이고, AdaBoost는 잘못 분류한 샘플의 가중치를 높이는 방식이다.

## 앙상블 정리

- **앙상블** : 여러 기본 모델의 예측을 결합해서 더 좋은 성능/안정성을 얻는 기법

### 앙상블 유형
| 유형 | 특징 |
| --- | --- |
| Bagging | 다양한 훈련 데이터셋, 피처셋 사용, 병렬 학습 |
| Boosting | 학습기를 순차적으로 학습, 앞선 예측의 부족한 부분을 보완 |
| Stacking | 여러 모델의 예측 결과를 입력 특성으로 사용, 메타 학습기가 실제 정답을 예측 |

### 대표 구현 클래스 (앙상블 알고리즘) - scikit-learn
- **Bagging 계열** : `BaggingClassifier`, `RandomForestClassifier`
- **Boosting 계열** : `AdaBoostClassifier`, `GradientBoostingClassifier`
- **Stacking 계열** : `StackingClassifier`

### 앙상블 모델의 장점
- 개별 모델이 가지는 편향과 분산을 줄임
- 과적합의 위험을 감소
- 전반적인 예측 성능을 향상
- = 다양한 모델의 예측을 결합함으로써, 데이터의 복잡한 구조와 패턴을 더 잘 포착하여 더 높은 신뢰도를 지닌 예측 제공

## Bagging (Bootstrap Aggregating)

### 부트스트랩 : 무작위 복원 추출
- 통계적 추정을 위한 재표집 기법. 원래의 데이터셋에서 반복하여 샘플을 추출하는 방법

### 배깅 과정
1. **샘플 추출**
   - 원본 데이터 세트에서 n개의 데이터 포인트를 무작위로 선택
   - '복원 추출' 방식 사용, 하나의 샘플이 여러 번 선택되거나 전혀 선택되지 않을 수도 있음
2. **부트스트랩 표본 생성**
   - 1의 샘플 추출 과정을 R번 반복, R개의 부트스트랩 표본 생성
   - R은 분석 결과의 안정성과 계산 비용을 고려하여 설정
   - 각 반복마다 독립적으로 샘플을 추출
3. **데이터 분석**
   - 생성된 각 부트스트랩 표본에 대해 분석 작업 수행
4. **결과 집계 및 해석**
   - 모든 부트스트랩 표본에 대한 분석 결과를 해석

### Random Forest
- 결정 트리가 모여 랜덤 포레스트를 구성
- 결정 트리의 단점 : 훈련 데이터에 오버피팅되는 경향 → 여러 개의 결정 트리를 통해 랜덤 포레스트 구성

#### 학습 Process
1. 원본 훈련 데이터에서 부트스트랩 샘플링으로 각 트리의 훈련 데이터 구성
2. 트리 생성 → 각 노드에서 분할할 때마다 일부 특성을 무작위로 선택
3. 선택한 특성 중 가장 좋은 분할을 찾아 노드 분할
4. 이 과정을 반복하여 하나의 트리 학습
5. 같은 방식으로 여러 개의 서로 다른 결정 트리 학습
6. 새로운 데이터에 대해 각 트리가 예측하고, 결과를 결합
   - 분류 : 다수결 또는 클래스별 예측 확률을 평균
   - 회귀 : 예측값 평균

#### 랜덤 포레스트의 두 가지 다양성
- **데이터의 다양성** : 트리마다 부트스트랩으로 훈련 샘플 구성
- **특성의 다양성** : 각 노드 분할마다 검토할 특성 무작위 선택

> 훈련 샘플과 분할에 사용하는 특성에 무작위성을 부여하여 여러 결정 트리를 학습하고, 이들의 예측을 결합하는 앙상블 모델  
> → 개별 트리의 예측이 흔들리는 현상을 줄여, 더 안정적인 성능 확보

## Boosting
- 약한 학습 알고리즘을 강한 학습 알고리즘으로 변환하는 프레임워크
- 여러 개의 약한 학습기를 순차적으로 학습시키면서 이전 학습기가 잘못 분류한 샘플에 더 많은 가중치를 부여하여 학습 진행
  - ← 전체 모델의 성능을 점진적으로 향상시키는 데 기여

### 아다부스트 (AdaBoost)
- 각 반복에서 약한 학습기를 학습시키고, 학습된 모델의 성능에 따라 학습 데이터의 가중치를 조정
- 잘못 분류된 샘플은 더 큰 가중치를 받아, 다음 학습기가 이 샘플들을 더 정확하게 분류하도록 유도
- 각 학습기의 훈련 데이터는 이전 학습기의 성능에 기반하여 결정, 새로운 데이터 세트는 이전 학습기들이 잘못 분류한 샘플들을 포함
  - ← 이전 학습기들의 오류를 보완, 전체 모델의 성능 향상
- 데이터의 복잡한 패턴을 효과적으로 학습할 수 있도록 돕고 과적합에 비교적 강함
  - ※ 참고 : 노이즈나 이상치가 많으면 그 샘플에 가중치가 계속 몰려 과적합될 수 있음
- 다양한 유형의 기반 학습기와 결합될 수 있어, 분류 및 회귀 문제 모두에 적용 가능 (유연성)

#### 학습 Process (AdaBoost)
1. **초기화** : 모든 훈련 샘플에 동일한 가중치 부여
2. **반복 학습**
   - 현재 샘플 가중치를 반영하여 약한 학습기 하나를 학습
   - 학습한 모델의 가중 오류율 계산 (틀린 샘플의 가중치를 합산하여 평가)
   - 가중 오류율을 바탕으로 모델 가중치 결정
   - 오류율이 낮은 모델일수록 최종 예측에서 더 큰 영향력을 가짐
   - 잘못 분류된 샘플의 상대적 가중치를 높임 → 다음 모델이 해당 샘플을 더 중요하게 다루도록 함 (샘플 가중치)
