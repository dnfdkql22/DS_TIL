■ 모델성능평가
○ confusion matrix
- True Positive : 실제 Positive인 정답을 Positive라고 예측(True) / TP
- True Negative : 실제 Negative인 정답을 Negative라고 예측(True) / TN
- False Positive : 실제 Negative인 정답을 Positive라고 예측(False) - Type Ⅰ error / FP
- False Negative : 실제 Positive인 정답을 Nrgative라고 예측(False) - Type Ⅱ error / FN

○ 분류성능평가지표
- 정확도(Accuracy) : 전체 예측 중에 올바른 예측의 비율
- 정밀도(Precision) : 긍정(Positive)으로 예측한 것 중 실제로 맞춘 비율
예시) 즉 환자로 예측한 전체 사례 중 실제 환자의 비율
- 민감도(Sensitivity, Recall 재현율)
= 실제 긍정(Positive)를 얼마나 잘 예측했는지를 나타내는 지표
= 실제 긍정 사례 전체 중에서 모델에 의해 올바르게 식별된 참 긍정의 비율
- 특이도(Specificity) : 실제 Negative를 얼마나 잘 예측했는지를 나타내는 지표
예시) 환자가 아닌 사람을 아니다 라고 얼마나 잘 예측하는지 비율

* F1 Score
- 불균형 데이터의 분류 문제에서의 평갗척도로 사용
- 정밀도와 민감도의 조화 평균, 낮은 값에 더 많은 가중치를 부여
- 데이터가 불균형한 상태에서, Accuracy(정확도)로 성능을 평가하기엔 데이터 편향성이 나타나 성능 척도로 사용하기에는 부적합
- 거짓양성과 거짓음성의 중요성 사이의 균형을 유지해야 하는 경우 사용
※ 2 x 
* F1 점수가 1에 가까운 경우
= 모델의 정밀도와 재현율이 모두 높음을 의미, 모델이 양성을 예측하는데 있어서 매우정확, 실제 양성사례 대부분을 정확히 감지해냈다는 의미
* F1 점수가 낮은 경우
= 모델의 정밀도 또는 재현율(또는 둘 다)가 낮음을 의미, 모델이 양성을 예측하는데 있어서 정확도가 떨어지거나, 실제 양성 사례들을 놓치고 있다는 의미

- 데이터 손실을 초래할 수 있으므로 주의 필요

- 소수 클래스의 샘플에 더 높은 가중치를 부여한여 보델 학습과정에서 소수 클래스가 더 큰 영향력을 갖도록 하는 방법
* 앙상블 기법 - 소수 클래스에 대한 예측 성능을 향상

- 비대칭 데이터에서는 정확도(Accuracy)만으로 모델 성능을 평가하는 것이 적합하지 않음

○ 모델의 설명력
* SST(Sum of Squares Total) : 전체변동(평균기준)
-  (실제 값과 평균값 간의 차이의 제곱 합)
- 실제 값과 데이터의 전체평균 간의 차이를 제곱한 값의 합
= 데이터의 총 분산, 결정계수 를 계산 시 분모로 사용
- 전체 변동성 = 데이터의 전체적인 퍼짐 정도

* SSR(Sum of Squares Due to Regression) : 회귀모형이 설명한 변동(평균 -> 예측값)
-  (예측값과 평균값 간의 차이의 제곱 합)
- 모델이 예측한 추정값과 데잍터의 전체 평균 간의 차이를 제곱한 값의 합 데이터의 총 분산 중 모델이 얼마나 많은 부분을 설명하는지 나타냄
- 모델이 설명하는 변동성 = 예측값이 평균값과 얼마나 차이가 있는가?

* SSE(Sum of Squares Due to Error) : 설명 못한 변동(예측값 -> 실제값)
-  (실제값과 예측값 간의 차이의 제곱 합)
- 실제 값과 회귀모델에서 예측한 추정값 간의 차이 제겁의 합 모델오류의 척도
- 모델이 설명하지 못하는 변동성 = 실제값과 예측값 사이의 차이
- 모델이 예측하지 못한 오차(Actual - Predicted)의 제곱값

**  = 전체 분산을 모델에 의해 설명되는 분산과 어류로 인한 분산으로 분할
** SST = SSR + SSE`
= 전체 분산을 모델에 의해 설명되는 분산과 오류로 인한 분산으로 분할


○ 다중회귀 vs 단순회귀
* 단순 선형 회귀
- 하나의 독립변수와 하나의 종속 변수를 이용해 데이터 간의 선형관계를 모델링하는 방법
  (하나의 입력변수와 하나의 출력변수 사이의 관계를 학습)
- y = w1 ㆍ x1 + b(x1 : 입력변수, y : 출력변수, w1 : 회귀계수, b : 편향)

* 다중 선형 회귀
- 여러 독립변수를 사용하여 종속변수를 예측하는 회귀방법
- y = w1ㆍx1+w2ㆍx2+w3ㆍx3+b (x1, x2, x : 입력변수, y : 출력변수, w1...:회귀계수, b : 편향)
- 입력변수가 한 개면 직선, 두 개면 예측 결과는 3차원공간에서의 평면, 입력변수가 더 많아지면 예측결과가 초평면으로 표현 but 입력변수의 개수가 늘어도 선형모델
-> 각 특성의 가중합만으로 예측한다면 여전히 선형 모델
- 데이터의 관계가 가중합으로 잘 표현된다면 초평면만으로 충분한 성능 가능
- 다항 회귀 : 입력 특성을 다항식으로 확장한 뒤 선형회귀 적용 제곱항 등 <- 비선형 관계 표현
(이러한 특성은 분석가가 만들어야 모델이 자동으로 제곱항 등을 찾아 추가하지는 않음)
* 비선형 모델링
- 곡선 관계 : 온도가 적정수준까지 오르면 생산량 증가, 일정 수준 이상이면 감소
- 상호작용 : 광고비의 효과가 할인율에 따라 달라지는 경우
- 임계점 : 특정 온도를 넘으면 불량률이 급격히 증가하는 경우
