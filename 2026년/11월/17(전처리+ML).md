# ■ 데이터 전처리 (Data Preprocessing)

## 1. 데이터 전처리의 개념

- 데이터 분석 및 머신러닝 모델링을 수행하기 전에 원시 데이터를 분석 목적에 적합한 형태로 가공하는 과정
- 데이터의 품질을 높이고 분석 및 모델의 성능을 향상시키기 위한 작업

### ○ 데이터 전처리의 목적

- 데이터 품질 향상 : 결측치, 이상치, 중복 데이터 등을 처리
- 데이터 일관성 확보 : 데이터 형식과 자료형을 통일
- 분석 효율성 향상 : 불필요한 데이터 제거 및 필요한 데이터 추출
- 모델 성능 개선 : 머신러닝 모델이 학습하기 적합한 데이터 형태로 변환

## 2. 데이터 분할 (Data Splitting)

- 전체 데이터를 학습 및 평가 목적에 따라 여러 집합으로 나누는 과정
- 모델이 학습에 사용하지 않은 데이터에서도 얼마나 잘 예측하는지 평가하기 위해 수행

### ○ 학습 데이터 (Training Data)

- 모델의 학습에 사용하는 데이터
- 데이터의 패턴과 특성을 학습하여 예측 규칙을 생성

### ○ 검증 데이터 (Validation Data)

- 학습 과정에서 모델의 성능을 평가하고 하이퍼파라미터를 조정하는 데 사용하는 데이터
- 모델의 과적합 여부를 확인하고 최적의 모델을 선택하는 데 활용

### ○ 테스트 데이터 (Test Data)

- 최종 모델의 성능을 평가하기 위한 데이터
- 모델 학습 및 하이퍼파라미터 조정에 사용하지 않음
- 실제 새로운 데이터에 대한 모델의 일반화 성능을 평가

### ○ 데이터 분할 예시

| 구분 | 비율 | 목적 |
|---|---:|---|
| 학습 데이터 | 70% | 모델 학습 |
| 검증 데이터 | 15% | 모델 성능 확인 및 조정 |
| 테스트 데이터 | 15% | 최종 성능 평가 |

※ 데이터의 특성과 양에 따라 분할 비율은 달라질 수 있습니다.

## 3. 교차검증 (Cross Validation)

- 데이터를 여러 개의 부분집합으로 나누어 학습과 검증을 반복하는 방법
- 특정 데이터 분할에만 의존하지 않고 모델의 성능을 보다 안정적으로 평가하기 위해 사용

### ○ K-Fold Cross Validation

- 전체 데이터를 K개의 동일하거나 유사한 크기의 그룹(Fold)으로 분할
- K개의 그룹 중 하나를 검증 데이터로 사용하고 나머지 K-1개 그룹을 학습 데이터로 사용
- 검증 데이터의 위치를 바꾸어 총 K번 학습과 평가를 반복
- 최종적으로 K번의 평가 결과를 평균하여 모델 성능을 확인

### ○ 교차검증의 목적

- 데이터 분할에 따른 평가 결과의 편차 감소
- 모델의 일반화 성능 확인
- 제한된 데이터의 효율적인 활용

# ■ 데이터 전처리 - 데이터 변환 (Data Transformation)

## 1. 결측치 (Missing Values)

- 데이터 수집 및 저장 과정에서 값이 누락된 상태
- 결측치가 존재하면 분석 결과가 왜곡되거나 모델 학습에 문제가 발생할 수 있음

### ○ 결측치 처리 방법

| 처리 방법 | 설명 |
|---|---|
| 삭제 | 결측치가 포함된 행 또는 열을 제거 |
| 평균 대체 | 수치형 데이터의 결측치를 평균값으로 대체 |
| 중앙값 대체 | 수치형 데이터의 결측치를 중앙값으로 대체 |
| 최빈값 대체 | 가장 자주 나타나는 값으로 대체 |
| 특정값 대체 | 0, Unknown 등 지정한 값으로 대체 |

### ○ 결측치 처리 시 고려사항

- 결측치가 발생한 원인 확인
- 결측치의 비율 및 분포 확인
- 평균과 중앙값 중 데이터 분포에 적합한 방법 선택
- 결측치 삭제로 인한 데이터 손실 여부 확인

## 2. 이상치 (Outlier)

- 다른 데이터와 비교했을 때 지나치게 크거나 작은 값을 가지는 관측치
- 데이터의 일반적인 분포에서 크게 벗어나는 값

### ○ 이상치 발생 원인

- 데이터 입력 오류
- 측정 장비의 오류
- 데이터 수집 과정의 문제
- 실제로 발생한 극단적인 관측값

### ○ 이상치 처리 방법

| 처리 방법 | 설명 |
|---|---|
| 삭제 | 이상치가 포함된 데이터 제거 |
| 대체 | 이상치를 평균, 중앙값 등으로 대체 |
| 변환 | 로그 변환 등을 통해 데이터 분포 조정 |
| 유지 | 실제 의미가 있는 값이라면 그대로 사용 |

### ○ IQR (Interquartile Range)

- 사분위수 범위를 이용하여 이상치를 판단하는 방법
- IQR은 제3사분위수(Q3)에서 제1사분위수(Q1)를 뺀 값

\[
IQR = Q3 - Q1
\]

- 이상치 판단 기준

\[
하한값 = Q1 - 1.5 \times IQR
\]

\[
상한값 = Q3 + 1.5 \times IQR
\]

- 하한값보다 작거나 상한값보다 큰 데이터를 일반적인 이상치 판단 기준으로 사용

※ 이상치 기준에 해당한다고 해서 반드시 잘못된 데이터는 아닙니다.

## 3. 데이터 타입 변환

- 데이터의 자료형을 분석 목적에 맞게 변경하는 과정
- 문자열로 저장된 숫자를 수치형으로 변경하거나 숫자를 문자열로 변경할 때 사용

### ○ 주요 데이터 타입

| 자료형 | 설명 | 예시 |
|---|---|---|
| int | 정수형 | 10, 20, 30 |
| float | 실수형 | 10.5, 20.3 |
| str | 문자열 | "Python", "100" |
| bool | 논리형 | True, False |

### ○ `to_numeric()`

- 데이터를 숫자형으로 변환하는 Pandas 함수
- 숫자로 변환할 수 없는 값이 존재할 때 `errors` 옵션을 활용할 수 있음

    ```python
    import pandas as pd

    df["age"] = pd.to_numeric(df["age"], errors="coerce")
    ```

- `errors="raise"` : 변환할 수 없는 값이 있으면 오류 발생
- `errors="coerce"` : 변환할 수 없는 값을 NaN으로 처리
- `errors="ignore"` : 변환할 수 없는 값이 있으면 원래 값을 유지

### ○ `astype()`

- 데이터의 자료형을 지정한 타입으로 변환하는 함수

    ```python
    df["age"] = df["age"].astype(int)
    df["price"] = df["price"].astype(float)
    df["name"] = df["name"].astype(str)
    ```

- 지정한 자료형으로 변환할 수 없는 값이 있으면 오류가 발생할 수 있음

## 4. 범주형 데이터 변환 (Categorical Data Encoding)

- 문자열이나 범주 형태의 데이터를 머신러닝 모델이 처리할 수 있도록 숫자 형태로 변환하는 과정
- 대표적인 방법으로 원-핫 인코딩과 레이블 인코딩 등이 있음

### ○ 원-핫 인코딩 (One-Hot Encoding)

- 범주형 데이터를 각 범주에 해당하는 별도의 열로 변환하는 방법
- 해당 범주에 해당하면 1, 해당하지 않으면 0으로 표현

예시: 색상 데이터

| 색상 | Red | Blue | Green |
|---|---:|---:|---:|
| Red | 1 | 0 | 0 |
| Blue | 0 | 1 | 0 |
| Green | 0 | 0 | 1 |

### ○ Pandas 원-핫 인코딩

    ```python
    import pandas as pd

    df_encoded = pd.get_dummies(df, columns=["color"])
    ```

- `pd.get_dummies()` : 범주형 변수를 원-핫 인코딩으로 변환
- `columns` : 변환할 열 지정

### ○ 원-핫 인코딩의 특징

- 범주 간에 임의적인 크기나 순서를 부여하지 않음
- 범주별로 새로운 열이 생성됨
- 범주의 종류가 많으면 열의 개수가 증가하여 데이터 차원이 커질 수 있음

# ■ 머신러닝 (Machine Learning)

## 1. 머신러닝의 개념

- 컴퓨터가 명시적으로 모든 규칙을 프로그래밍하지 않아도 데이터로부터 패턴과 규칙을 학습하는 인공지능의 한 분야
- 학습한 패턴을 바탕으로 새로운 데이터에 대한 예측이나 판단을 수행

### ○ 머신러닝의 기본 과정

1. 데이터 수집
2. 데이터 전처리
3. 학습 데이터와 테스트 데이터 분할
4. 모델 선택
5. 모델 학습
6. 모델 평가
7. 새로운 데이터 예측

## 2. 머신러닝의 종류

### ○ 지도학습 (Supervised Learning)

- 정답(Label)이 포함된 데이터를 사용하여 학습하는 방법
- 입력 데이터(X)와 정답(Y)의 관계를 학습하여 새로운 데이터의 결과를 예측

| 구분 | 설명 | 예시 |
|---|---|---|
| 분류(Classification) | 데이터를 미리 정해진 범주로 구분 | 스팸 메일 분류, 질병 여부 예측 |
| 회귀(Regression) | 연속적인 수치 값을 예측 | 주택 가격 예측, 매출 예측 |

### ○ 비지도학습 (Unsupervised Learning)

- 정답(Label)이 없는 데이터를 사용하여 학습하는 방법
- 데이터 내부의 패턴이나 구조, 유사성을 찾아내는 방식

| 구분 | 설명 | 예시 |
|---|---|---|
| 군집화(Clustering) | 유사한 특성을 가진 데이터를 그룹으로 분류 | 고객 유형 분류 |
| 차원 축소(Dimensionality Reduction) | 데이터의 변수 수를 줄여 핵심 정보 추출 | PCA |

### ○ 강화학습 (Reinforcement Learning)

- 에이전트가 환경과 상호작용하면서 보상(Reward)을 최대화하는 방향으로 학습하는 방법
- 행동에 따른 보상과 패널티를 통해 최적의 행동 전략을 학습

| 구성 요소 | 설명 |
|---|---|
| Agent | 행동을 수행하는 주체 |
| Environment | 에이전트가 상호작용하는 환경 |
| Action | 에이전트가 선택하는 행동 |
| Reward | 행동에 따른 보상 |
| State | 현재 환경의 상태 |

## 3. 모델 학습과 예측

- 모델은 학습 데이터를 바탕으로 입력 변수(X)와 출력 변수(Y) 사이의 관계를 학습
- 학습이 완료된 모델에 새로운 입력 데이터를 제공하면 예측 결과를 출력

### ○ 기본 구조

\[
X \rightarrow Model \rightarrow Y
\]

- X : 입력 데이터(Feature)
- Model : 데이터를 학습한 머신러닝 모델
- Y : 예측 결과(Target)

# ■ 인공신경망 모델링 (Artificial Neural Network Modeling)

## 1. 인공신경망 (Artificial Neural Network, ANN)

- 인간의 생물학적 신경망 구조에서 영감을 얻어 만들어진 머신러닝 모델
- 여러 개의 인공 뉴런을 연결하여 데이터의 패턴과 복잡한 관계를 학습하는 방법

### ○ 인공신경망의 기본 구조

1. 입력층(Input Layer)
   - 외부에서 입력 데이터를 전달받는 계층
   - 입력 변수(Feature)를 전달

2. 은닉층(Hidden Layer)
   - 입력 데이터를 바탕으로 특징과 패턴을 학습하는 계층
   - 여러 개의 뉴런으로 구성될 수 있음

3. 출력층(Output Layer)
   - 학습된 결과를 바탕으로 최종 예측값을 출력하는 계층

### ○ 뉴런(Neuron)

- 입력값에 가중치를 적용하고 편향을 더한 다음 활성화 함수를 통과시켜 결과를 출력하는 기본 단위

\[
z = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
\]

- x : 입력값
- w : 가중치(Weight)
- b : 편향(Bias)
- z : 가중합

### ○ 활성화 함수 (Activation Function)

- 뉴런의 출력값을 결정하는 함수
- 신경망에 비선형성을 부여하여 복잡한 패턴을 학습할 수 있도록 함

| 활성화 함수 | 특징 |
|---|---|
| Sigmoid | 출력값을 0과 1 사이로 변환 |
| ReLU | 입력값이 0보다 작으면 0, 크면 입력값을 그대로 출력 |
| Tanh | 출력값을 -1과 1 사이로 변환 |
| Softmax | 여러 클래스의 출력값을 확률 형태로 변환 |

### ○ 인공신경망의 학습 과정

1. 입력 데이터 전달
2. 가중치와 편향을 이용한 계산
3. 활성화 함수를 통한 출력
4. 예측값과 실제값 비교
5. 손실 함수(Loss Function)를 이용한 오차 계산
6. 역전파(Backpropagation)를 통한 가중치 조정
7. 오차가 줄어들도록 반복 학습

### ○ 손실 함수 (Loss Function)

- 모델의 예측값과 실제 정답 사이의 차이를 수치로 계산하는 함수
- 손실값이 작아질수록 예측 결과가 실제값에 가까워지는 것을 의미

### ○ 역전파 (Backpropagation)

- 출력층에서 계산한 오차를 입력층 방향으로 전달하면서 각 가중치가 오차에 미치는 영향을 계산하는 방법
- 계산된 기울기를 바탕으로 가중치를 업데이트

### ○ 경사하강법 (Gradient Descent)

- 손실 함수의 기울기를 이용하여 손실값이 작아지는 방향으로 가중치를 업데이트하는 최적화 방법

# ■ GPT 분류 모델링

## 1. GPT (Generative Pre-trained Transformer)

- 대규모 텍스트 데이터를 사전 학습한 생성형 인공지능 모델
- Transformer 구조를 기반으로 문맥과 단어 사이의 관계를 학습
- 학습한 정보를 바탕으로 텍스트 생성, 요약, 번역, 분류 등 다양한 작업을 수행

### ○ GPT의 주요 특징

- Generative : 새로운 텍스트를 생성
- Pre-trained : 대규모 데이터를 이용하여 사전 학습
- Transformer : 문맥과 단어 간의 관계를 학습하는 신경망 구조

## 2. 분류 모델링 (Classification Modeling)

- 입력된 데이터를 미리 정의된 범주(Class) 중 하나 또는 여러 개로 구분하는 작업
- 데이터의 특징을 학습하여 새로운 데이터가 어떤 범주에 해당하는지 예측

### ○ 분류 모델의 기본 구조

\[
Input \rightarrow Model \rightarrow Class
\]

- Input : 분류할 데이터
- Model : 입력 데이터의 특징과 패턴을 학습한 모델
- Class : 최종적으로 예측한 분류 결과

## 3. 인공신경망을 이용한 예측

**Artificial Neural Network Modeling**

- If we can train a model to map X to Y based on a labelled dataset then it can be used to predict.

**번역**
- 라벨(Label)이 지정된 데이터셋을 기반으로 X를 Y에 매핑하는 모델을 학습시킬 수 있다면, 해당 모델을 예측에 사용할 수 있습니다.

### ○ 문장 해석

- X : 입력 데이터(Feature)
- Y : 정답 데이터(Label 또는 Target)
- Labelled Dataset : 정답이 지정되어 있는 데이터셋
- Mapping : 입력 데이터와 정답 데이터 사이의 관계를 학습하는 과정
- Predict : 학습된 관계를 바탕으로 새로운 입력 데이터의 결과를 예측하는 과정

### ○ 예시

| 입력 데이터(X) | 정답 데이터(Y) |
|---|---|
| 공부 시간 | 시험 점수 |
| 주택 면적 | 주택 가격 |
| 이메일 내용 | 스팸 여부 |

- 학습 데이터에 포함된 X와 Y의 관계를 모델이 학습
- 학습이 완료되면 새로운 X를 입력하여 Y를 예측
- 새로운 데이터에 대한 예측 결과를 실제 정답과 비교하여 모델 성능 평가

## 4. 핵심 정리

| 구분 | 핵심 내용 |

| 비지도학습 | 정답이 없는 데이터에서 패턴과 구조 탐색 |
| 강화학습 | 보상을 최대화하는 방향으로 행동 학습 |
| 인공신경망 | 뉴런을 연결하여 복잡한 데이터 패턴 학습 |

| 분류 | 데이터를 미리 정의된 범주로 구분 |
| 예측 | 학습한 X와 Y의 관계를 바탕으로 새로운 Y 추정 |
