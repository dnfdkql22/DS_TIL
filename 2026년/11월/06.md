# 데이터 시각화 (Data Visualization)

## 1. 시각화 + 기초통계 + EDA + Feature Engineering

- **EDA(탐색적 데이터 분석)**를 수행하여 컬럼 구조, 데이터 타입, 결측치, 기초 통계량, 범주별 빈도 등을 확인하고 데이터의 구조와 분포 특성을 해석하여 분석 방향과 필요한 인사이트 도출
- 분석 목적에 적합한 차트를 작성하고, 데이터를 쉽게 읽을 수 있도록 시각적 요소 설정
- 변수의 수와 전달 목적에 따라 적합한 차트 유형을 선택
- 결측치 및 이상치를 탐지하고, 데이터 특성에 맞는 처리 방법을 선택하여 분석 가능한 상태로 정제
- 데이터 특성에 맞는 조건을 설정하여 필요한 데이터를 추출하고 파생변수 생성
- 결측치, 중복 데이터, 이상치가 분석 결과에 미치는 영향을 이해하고 각 처리 방법의 장단점 파악

---

## 2. EDA (Exploratory Data Analysis)

**EDA : 탐색적 데이터 분석**

- 데이터를 심층적으로 이해하고 주요 특징을 요약하는 과정
- 통계적 분석과 시각화를 통해 데이터에 숨겨진 패턴 및 변수 간 관계성을 발견

### 2-1. 목적

| 구분 | 설명 |
|---|---|
| 데이터 이해 | 데이터의 구조, 변수 유형, 분포 및 통계적 특성(평균, 표준편차 등) 파악 |
| 패턴 및 관계 발견 | 변수 간 숨겨진 관계와 데이터의 패턴 식별 |
| 문제점 식별 | 결측값, 이상치, 데이터 불일치 등 데이터 품질 문제 발견 및 처리 방법 결정 |
| 가설 생성 및 검증 | 데이터를 바탕으로 의미 있는 가설을 수립하거나 기존 가정 검증 |
| 최적의 분석기법 선택 | 데이터 특성을 이해하여 적합한 분석 방법 및 머신러닝 모델 선택 |

### 2-2. CRISP-DM

**CRISP-DM (Cross Industry Standard Process for Data Mining)**

- 데이터 마이닝 프로젝트를 체계적으로 수행하기 위한 산업 표준 프로세스
- 데이터 분석의 전체 과정을 단계별로 구분하여 진행하는 방법론

#### ① Business Understanding (비즈니스 이해)

- 분석 목표 및 성공 지표 정의
- KPI 및 Target(타깃) 정의
- 목표 달성에 필요한 데이터의 양과 라벨 존재 여부 검토
- Feasibility(실현 가능성 및 타당성) 검토
- 초기 가설 수립 및 측정 기준 정의

#### ② Data Understanding (데이터 이해)

- Explore Data : 데이터 탐색
- Verify Data Quality : 데이터 품질 검증
- 데이터의 의미 파악 : 변수의 의미, 단위, 범위 등 확인
- 데이터의 분포, 패턴 및 변수 간 관계 파악
  - 단변량 분석(Univariate Analysis)
  - 다변량 분석(Multivariate Analysis)
- 결측치, 이상치, 오류, 중복 데이터 등 품질 문제 발견

## 3. 데이터 시각화 (Data Visualization)

- 차트, 그래프, 인포그래픽, 애니메이션 등 그래픽 요소를 활용하여 데이터를 시각적으로 표현하는 것
- 복잡한 데이터의 관계와 분석 결과를 이해하기 쉬운 형태로 전달하는 방법

### 3-1. 목적 및 활용

- 데이터 분석 전 데이터의 전반적인 구조와 분포 파악
- 데이터의 패턴 및 변수 간 관계를 시각적으로 확인
- 데이터 전처리에 필요한 아이디어 획득
- 데이터의 특성과 결과를 정확하게 해석
- 분석 결과를 직관적으로 전달하여 의사결정 지원

### 3-2. 데이터 유형에 따른 구분

| 상위 구분 | 하위 구분 | 특징 | 주요 분석 방법 |
|---|---|---|---|
| 양적 데이터 (정량적 데이터) | 이산형 데이터 | 셀 수 있는 개별적인 수치 | 빈도, 합계, 평균 등 |
| 양적 데이터 (정량적 데이터) | 연속형 데이터 | 측정할 수 있으며 연속적인 값을 가질 수 있는 수치 | 평균, 중앙값, 표준편차, 분포 등 |
| 질적 데이터 (정성적 데이터) | 명목형 데이터 | 순서 없이 범주를 구분하는 데이터 | 범주별 빈도 및 비율 |
| 질적 데이터 (정성적 데이터) | 순서형 데이터 | 일정한 순서나 등급이 존재하는 데이터 | 순위, 빈도, 비율 등 |

#### 데이터 구분에 따른 기초 분석

- **수치형 데이터 (양적 데이터)**
  - 기초 통계량을 활용하여 숫자로 요약
  - 평균, 중앙값, 최빈값, 분산, 표준편차 등

- **범주형 데이터 (질적 데이터)**
  - 범주별 빈도수 및 비율을 활용하여 요약
  - 빈도표, 교차표, 비율 등

## 4. Matplotlib

- 파이썬의 대표적인 데이터 시각화 라이브러리
- 간단한 플롯부터 복잡한 그래프까지 다양한 형태의 시각화 지원

### 4-1. 주요 기능

- **다양한 그래프 생성** : 선 그래프, 막대 그래프, 히스토그램, 산점도 등
- **고급 사용자 정의** : 축, 레이블, 범례, 색상, 스타일 등을 세밀하게 조정 가능
- **다양한 출력 옵션** : 그래프를 다양한 형식으로 저장하거나 웹 애플리케이션에 활용 가능

### 4-2. 효과

- **시각적 이해** : 복잡한 데이터를 시각적으로 표현하여 데이터 이해도 향상
- **의사결정 지원** : 데이터의 패턴과 경향을 파악하여 합리적인 의사결정 지원
- **커뮤니케이션 강화** : 분석 결과를 직관적으로 전달하여 원활한 정보 공유

## 5. 주요 시각화 유형

### 5-1. 선 그래프 (Line Chart)

- 선을 이용하여 데이터의 변화와 추세를 표현하는 그래프
- 시간의 흐름에 따른 데이터 변화를 나타낼 때 효과적

**주요 활용 기능**

- **그리드 표시** : X축과 Y축의 눈금을 선으로 연결하여 격자 형태로 표시
- **구간 확대 및 축소** : X축과 Y축의 최댓값 및 최솟값을 조정하여 특정 구간 강조
- **데이터 강조** : 특정 데이터에 화살표와 문자를 함께 표시하여 주요 지점 설명

**주요 사용 목적**
- 시간에 따른 데이터 변화 및 추세 파악
- 특정 시점의 급격한 변화 확인
- 여러 데이터의 시간별 변화 비교

### 5-2. 막대 그래프 (Bar Chart)

- 막대의 길이 또는 높이로 데이터의 크기를 표현하는 그래프
- 항목이나 범주 간 값을 비교할 때 유용

**주요 사용 목적**
- 항목별 수치 비교
- 범주별 빈도 및 비율 비교
- 그룹 간 차이 확인

### 5-3. 도수분포표 (Frequency Distribution Table)

- 수치 데이터를 여러 개의 구간(계급)으로 나누고, 각 구간에 속하는 데이터의 개수(도수)를 정리한 표

**주요 구성 요소**

- **계급(Class)** : 데이터를 구분하기 위해 나눈 각 구간
- **도수(Frequency)** : 각 구간에 포함된 데이터의 개수
- **계급값(Class Mark)** : 각 구간의 중앙값

### 5-4. 히스토그램 (Histogram)

- 연속형 데이터를 여러 구간(Bin)으로 나누고, 각 구간에 포함된 데이터의 빈도수를 막대로 표현하는 그래프
- 데이터의 분포와 형태를 시각적으로 확인할 때 사용

**주요 구성 요소**

- **Bin(구간)** : 데이터 범위를 여러 구간으로 나눈 것
  - 동일한 크기 또는 사용자가 지정한 크기로 설정 가능
- **막대** : 각 구간에 속하는 데이터의 빈도수를 표현
  - 막대의 높이 = 해당 구간에 속하는 데이터의 개수
- **X축** : 데이터의 값 또는 구간 범위
- **Y축** : 각 구간에 속하는 데이터의 빈도수

**주요 사용 목적**

- **데이터 분포 확인** : 정규분포 여부, 한쪽으로 치우친 분포 등 확인
- **중심 경향 파악** : 평균, 중앙값, 최빈값 등의 위치를 시각적으로 확인
- **데이터의 변동성 파악** : 데이터가 얼마나 넓게 퍼져 있는지 확인

### 5-5. 산점도 (Scatter Plot)

- 두 변수 간의 관계를 좌표를 이용하여 시각적으로 표현한 그래프
- 각 데이터 포인트는 X축과 Y축의 값을 좌표로 하여 그래프에 표시

**주요 사용 목적**

- 변수 간 상관관계 파악
- 데이터의 패턴 및 추세 확인
- 변수 간 선형 및 비선형 관계 확인
- 이상치 및 특이한 데이터 포인트 탐지

## 6. 차트 유형 선택 기준

| 차트 유형 | 주요 목적 | 적합한 데이터 |
|---|---|---|
| 선 그래프 | 시간에 따른 변화 및 추세 파악 | 시간 데이터와 수치형 데이터 |
| 막대 그래프 | 항목별 크기 및 빈도 비교 | 범주형 데이터와 수치형 데이터 |
| 도수분포표 | 구간별 데이터 빈도 정리 | 수치형 데이터 |
| 히스토그램 | 데이터의 분포 및 형태 파악 | 연속형 데이터 |
| 산점도 | 두 변수 간 관계 및 상관관계 파악 | 두 개의 수치형 변수 |

**핵심 정리**

- 시간에 따른 변화 → 선 그래프
- 항목 간 크기 비교 → 막대 그래프
- 구간별 데이터 개수 확인 → 도수분포표
- 데이터의 분포 형태 확인 → 히스토그램
- 두 변수 간 관계 확인 → 산점도
