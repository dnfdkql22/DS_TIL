# 자료구조 및 데이터 전처리

## 1. 힙(Heap)

- 여러 데이터 중에서 가장 작은 값이나 가장 큰 값을 반복적으로 빠르게 선택할 때 사용하는 자료구조
- 파이썬에서는 힙을 직접 구현하기보다 표준 라이브러리인 `heapq`를 사용할 수 있다.
- `heapq`는 기본적으로 최소 힙(Min Heap)으로 동작하기 때문에 가장 작은 값부터 꺼낼 수 있다.

### 주요 기능

| 함수 | 설명 |
|---|---|
| `heapq.heappush(heap, value)` | 힙에 새로운 값을 추가 |
| `heapq.heappop(heap)` | 가장 작은 값을 꺼내면서 제거 |
| `heapq.heapify(list)` | 기존 리스트를 힙 구조로 변환 |
| `heapq.heappushpop(heap, value)` | 값을 추가한 후 가장 작은 값을 꺼냄 |
| `heapq.nlargest(n, iterable)` | 가장 큰 값부터 n개 반환 |
| `heapq.nsmallest(n, iterable)` | 가장 작은 값부터 n개 반환 |

### 사용 예시

```python
import heapq

numbers = []

heapq.heappush(numbers, 5)
heapq.heappush(numbers, 2)
heapq.heappush(numbers, 8)

print(heapq.heappop(numbers))
print(heapq.heappop(numbers))
```

**출력 결과**
```text
2
5
```

- 값을 추가할 때마다 힙 구조를 유지한다.
- `heappop()`을 사용하면 가장 작은 값부터 순서대로 꺼낼 수 있다.

※ 힙을 사용하는 이유

- 리스트에서 매번 최솟값을 찾을 수도 있지만, 최솟값을 여러 번 선택해야 하는 문제라면 힙을 활용하는 것이 효율적이다.
- 힙은 값을 추가하거나 최솟값을 꺼낼 때 일반적으로 O(log n)의 시간 복잡도를 가진다.

### 가장 큰 값을 먼저 꺼내려면?

- `heapq`는 기본적으로 가장 작은 값을 먼저 꺼낸다.
- 하지만 값을 넣을 때 숫자 앞에 `-`를 붙여 음수로 변환하면 가장 큰 값을 먼저 꺼내는 것처럼 활용할 수 있다.
- 값을 꺼낼 때 다시 음수로 변환하면 원래 숫자를 얻을 수 있다.

**사용 예시**

```python
import heapq

numbers = []

heapq.heappush(numbers, -5)
heapq.heappush(numbers, -2)
heapq.heappush(numbers, -8)

print(-heapq.heappop(numbers))
print(-heapq.heappop(numbers))
```

**출력 결과**
```text
8
5
```

※ 핵심 정리

- 최소 힙 : 가장 작은 값을 먼저 꺼냄
- 최대 힙 : 음수로 변환하여 저장하고, 꺼낼 때 다시 양수로 변환
- 힙은 우선순위가 높은 데이터를 반복적으로 선택하는 문제에 적합하다.

# 2. 데이터 전처리(Data Preprocessing)

- 원시 데이터를 분석이나 모델링에 적합한 형태로 가공하는 과정
- 분석을 시작하기 전에 **무엇을 확인할 것인지**, **어떤 의사결정을 위한 분석인지** 먼저 정의해야 한다.

## 핵심 개념

- 원본 데이터에는 분석을 방해하는 잘못된 값이 포함될 수 있다.
- 잘못된 데이터를 그대로 사용하면 분석 결과도 잘못될 수 있다.
- 데이터 전처리는 분석 목적에 맞게 데이터를 정리하고 변환하는 과정이다.

### 전처리를 해야 하는 이유

- 원본 데이터에는 결측값, 이상값, 중복 데이터 등이 포함되어 있어 분석 결과를 왜곡할 수 있다.
- 올바른 분석을 위해서는 데이터를 먼저 확인하고 정제하는 과정이 필요하다.

### 주요 전처리 작업

| 구분 | 설명 |
|---|---|
| 결측치 처리 | 값이 비어 있는 데이터 처리 |
| 이상치 처리 | 일반적인 범위에서 크게 벗어난 데이터 확인 및 처리 |
| 중복 데이터 제거 | 동일한 데이터가 반복되는 문제 해결 |
| 데이터 타입 변환 | 분석 목적에 맞게 데이터 형식 변경 |
| 데이터 형식 통일 | 날짜, 단위, 문자열 등의 형식 통일 |
| 데이터 인코딩 | 범주형 데이터를 숫자 형태로 변환 |

# 3. Pandas

- 판다스(Pandas)는 파이썬에서 데이터를 조작하고 분석할 수 있도록 도와주는 오픈소스 라이브러리이다.
- 스프레드시트(엑셀)처럼 행과 열로 구성된 표 형태의 데이터를 파이썬 코드로 다룰 수 있게 해준다.
- 데이터 과학 분야에서 널리 사용되는 데이터 분석 도구이다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 대용량 데이터 처리 | 수백만 행의 데이터도 효율적으로 처리 |
| 데이터 조작 | 필터링, 정렬, 집계, 변환 등 다양한 연산 지원 |
| 시각화 연동 | Matplotlib, Seaborn 등과 쉽게 연계 |
| 구조화 분석 | CSV, Excel, JSON, SQL 등 다양한 형식의 데이터 처리 |
| 데이터 정제 | 결측치, 중복 데이터, 이상값 등의 처리 |

# 4. Pandas의 핵심 자료구조

## 4-1. 데이터프레임(DataFrame)

- 데이터프레임은 판다스의 핵심 자료구조로, 행과 열로 이루어진 2차원 표 형태의 데이터이다.
- 엑셀의 시트와 유사하며, 각 행은 하나의 데이터 레코드를, 각 열은 하나의 특성을 나타낸다.
- 데이터프레임은 행을 구분하는 인덱스(Index)와 열을 구분하는 컬럼(Column)을 가진다.

## 4-2. 시리즈(Series)

- 시리즈는 1차원 데이터를 담는 자료구조로, 데이터프레임의 하나의 열에 해당한다.
- 각 값에는 대응하는 인덱스가 붙어 있다.
- 리스트와 달리 인덱스 레이블을 기반으로 데이터에 접근할 수 있다.
- 데이터프레임에서 하나의 컬럼을 선택하면 시리즈가 반환된다.

### DataFrame과 Series 비교

| 구분 | DataFrame | Series |
|---|---|---|
| 차원 | 2차원 | 1차원 |
| 구조 | 행과 열 | 하나의 데이터 열 |
| 구성 | 여러 컬럼 | 하나의 컬럼 |
| 예시 | 엑셀의 시트 | 엑셀의 한 열 |

# 5. 데이터 확인 및 기본 정보 파악

데이터를 받았을 때 최우선으로 해야 할 사항

- 데이터를 받았을 때 바로 분석에 들어가는 것이 아니라, 먼저 데이터가 어떤 형태로 구성되어 있는지 확인해야 한다.
- 컬럼은 몇 개인지, 데이터 타입은 무엇인지, 결측값은 얼마나 있는지 등의 기본 정보를 파악해야 적절한 전처리 및 분석 방향을 결정할 수 있다.

## 주요 메서드

| 메서드 | 설명 |
|---|---|
| `head(n)` | 데이터의 앞부분 n개 행 확인 |
| `tail(n)` | 데이터의 뒷부분 n개 행 확인 |
| `shape` | 데이터의 행과 열 개수 확인 |
| `columns` | 컬럼명 확인 |
| `dtypes` | 각 컬럼의 데이터 타입 확인 |
| `rename()` | 컬럼명 변경 |
| `info()` | 데이터 타입, 컬럼별 결측치 등 전체 정보 확인 |

## 사용 예시

```python
import pandas as pd

orders = pd.DataFrame({
    "order_id": [1001, 1002, 1003, 1004, 1005, 1006],
    "customer": ["민수", "지수", "철수", "영희", "준호", "수진"],
    "price": [15000, 32000, 8000, 45000, 12000, 27000]
})

# 데이터 앞부분 확인
print(orders.head(3))

# 데이터 뒷부분 확인
print(orders.tail(2))

# 행과 열 개수 확인
print(orders.shape)

# 컬럼명 확인
print(orders.columns)

# 데이터 타입 확인
print(orders.dtypes)

# 컬럼명 변경
orders = orders.rename(columns={"price": "order_price"})

print(orders.columns)
```

### 결과 해석

- `head()`와 `tail()`을 사용하면 실제 데이터가 어떤 형태로 들어 있는지 빠르게 확인할 수 있다.
- `shape`의 결과 `(6, 3)`은 데이터가 6개 행과 3개의 열로 구성되어 있다는 의미이다.
- `columns`로 컬럼명을 확인할 수 있다.
- `dtypes`로 각 컬럼에 어떤 데이터 타입이 저장되어 있는지 확인할 수 있다.
- 필요하다면 `rename()`을 이용해 분석하기 편한 컬럼명으로 변경할 수 있다.

# 6. 데이터 타입 확인과 변환

- 데이터가 숫자처럼 보여도 실제 데이터 타입은 문자열일 수 있다.
- `astype()`을 사용하면 원하는 데이터 타입으로 변환할 수 있다.
- 날짜 데이터는 `pd.to_datetime()`으로 변환하면 이후 날짜 기반 분석에 활용할 수 있다.

## 주요 데이터 타입

| 타입 | 설명 | 예시 |
|---|---|---|
| `int64` | 정수형 | 10, 100, 200 |
| `float64` | 실수형 | 10.5, 20.3 |
| `object` | 문자열 등 일반 객체 | "Python", "서울" |
| `bool` | 논리형 | True, False |
| `datetime64` | 날짜 및 시간 | 2026-11-10 |
| `category` | 범주형 | 등급, 지역, 상품 유형 |

## 데이터 타입 변환

### ① astype()

- 분석 목적에 맞게 데이터 타입을 변경할 수 있다.

```python
orders["order_id"] = orders["order_id"].astype(str)

print(orders.dtypes)
```

### ② pd.to_datetime()

- 문자열이나 다른 형식의 날짜 데이터를 날짜 및 시간 타입으로 변환한다.

```python
orders["order_date"] = pd.to_datetime(orders["order_date"])
```

※ 날짜 형식으로 변환하면 연도, 월, 일, 요일 등의 정보를 활용한 분석이 가능하다.

# 7. 데이터 분포 파악

## 핵심 개념

- `describe()`는 수치형 데이터의 전체적인 분포를 빠르게 확인할 때 유용하다.
- `value_counts()`는 각 값이 몇 번 등장했는지 확인한다.
- `nunique()`는 중복을 제외한 고유한 값의 개수를 계산한다.
- `corr()`는 수치형 변수 간 상관관계를 계산한다.

## 7-1. describe() : 수치형 열 통계 요약

| 통계량 | 설명 | 눈여겨봐야 할 포인트 |
|---|---|---|
| count | 결측값을 제외한 데이터 수 | 전체 행 수와 비교하여 결측치 확인 |
| mean | 평균값 | median과 비교하여 분포의 치우침 확인 |
| std | 표준편차 | 데이터의 변동성 확인 |
| min | 최소값 | 물리적으로 불가능한 값이 있는지 확인 |
| 25% | 제1사분위수(Q1) | 하위 25% 기준값 |
| 50% | 중앙값(Median) | 데이터의 중앙 위치 |
| 75% | 제3사분위수(Q3) | 상위 25% 기준값 |
| max | 최대값 | 비정상적으로 큰 값이 있는지 확인 |

※ 추가 해석

- mean과 median의 차이가 크다면 데이터 분포가 한쪽으로 치우쳐 있을 가능성이 있다.
- std가 크다면 데이터의 변동성이 크다는 의미이다.
- min과 max를 통해 비정상적이거나 물리적으로 불가능한 값이 있는지 확인할 수 있다.
- Q1과 Q3을 활용하면 사분위 범위(IQR)를 계산하여 이상치를 판단할 수 있다.

## 7-2. value_counts() : 값별 빈도 확인

- 범주형 컬럼에서 각 값이 몇 번 등장하는지 확인한다.
- 특정 범주의 데이터가 얼마나 많이 분포하는지 파악할 수 있다.

```python
print(orders["customer"].value_counts())
```

## 7-3. nunique() : 고유값 개수 확인

- 중복을 제외한 고유한 값의 개수를 계산한다.
- 컬럼에 얼마나 다양한 값이 존재하는지 확인할 수 있다.
- 이러한 고유값의 개수를 카디널리티(Cardinality)라고 한다.

```python
print(orders["customer"].nunique())
```

## 7-4. corr() : 상관관계 확인

- 수치형 변수 간 상관관계를 계산한다.
- 변수 간 관계의 방향과 강도를 파악할 수 있다.
- 상관계수는 -1부터 +1까지의 값을 가진다.

```python
print(orders.corr(numeric_only=True))
```

※ `corr()`는 이후 데이터 시각화 및 탐색적 데이터 분석(EDA)에서 활용할 수 있다.

# 8. 결측치 처리

- 결측치(Missing Value)란 값이 존재해야 할 위치에 데이터가 없는 상태를 의미한다.
- 결측치를 적절하게 처리하지 않으면 통계 분석 및 머신러닝 모델의 결과에 영향을 줄 수 있다.

## 결측치 처리 방법 4가지

| 상황 | 처리 방법 | 설명 |
|---|---|---|
| 결측치가 매우 적고 무작위로 발생 | 행 삭제 | 결측치가 포함된 행 제거 |
| 이상치가 거의 없는 수치형 데이터 | 평균 대체 | 결측값을 평균으로 대체 |
| 큰 이상치가 존재하는 수치형 데이터 | 중앙값 대체 | 결측값을 중앙값으로 대체 |
| 범주형 데이터 | 최빈값 대체 | 가장 자주 등장하는 값으로 대체 |

## 주요 메서드

| 메서드 | 설명 |
|---|---|
| `isnull()` | 결측치 여부 확인 |
| `isna()` | 결측치 여부 확인 |
| `sum()` | 컬럼별 결측치 개수 계산 |
| `dropna()` | 결측치가 포함된 행 또는 열 삭제 |
| `fillna()` | 결측치를 특정 값으로 대체 |

### 사용 예시

```python
import pandas as pd

# 컬럼별 결측치 개수 확인
print(orders.isnull().sum())

# 결측치가 포함된 행 삭제
orders = orders.dropna()

# 평균값으로 결측치 대체
orders["price"] = orders["price"].fillna(orders["price"].mean())

# 중앙값으로 결측치 대체
orders["price"] = orders["price"].fillna(orders["price"].median())

# 최빈값으로 결측치 대체
orders["customer"] = orders["customer"].fillna(
    orders["customer"].mode()[0]
)
```

※ 주의사항

- 결측치 처리 방법은 데이터의 특성과 분석 목적에 따라 달라져야 한다.
- 평균 대체는 이상치에 영향을 크게 받으므로 주의해야 한다.
- 중앙값은 극단적인 값의 영향을 상대적으로 적게 받는다.
- 결측치가 발생한 이유와 패턴을 확인한 후 처리 방법을 결정하는 것이 중요하다.

# 핵심 정리
