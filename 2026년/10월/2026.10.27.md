## 1. 데이터 변동성(Variability)

### 1-1. 데이터 변동성이란?

데이터 변동성은 데이터가 평균값을 기준으로 얼마나 퍼져 있는지를 나타내는 개념이다.

단순히 평균값만 확인하는 것이 아니라 데이터가 어느 정도의 차이를 가지고 분포하는지 확인하는 것이 중요하다.

예를 들어 두 영화의 평균 평점이 모두 10점 만점에 5점이더라도 실제 평점 분포는 다를 수 있다.

| 구분 | 영화 A | 영화 B |
|---|---:|---:|
| 평점 0점 | 0명 | 50명 |
| 평점 5점 | 100명 | 0명 |
| 평점 10점 | 0명 | 50명 |
| 평균 평점 | 5점 | 5점 |

두 영화의 평균은 같지만 평점의 분포는 다르다.

- 영화 A: 대부분의 평가자가 5점을 부여함.
- 영화 B: 평가자들이 0점 또는 10점으로 극단적으로 나뉨.

따라서 평균만으로는 데이터의 특성을 충분히 파악할 수 없다.

### 1-2. 변동성 관련 제곱합

회귀분석에서는 데이터의 변동성을 다음과 같은 제곱합으로 구분할 수 있다.

| 구분 | 명칭 | 의미 |
|---|---|---|
| SST | Total Sum of Squares | 실제 데이터의 전체 변동성 |
| SSR | Regression Sum of Squares | 회귀모델이 설명하는 변동성 |
| SSE | Error Sum of Squares | 회귀모델이 설명하지 못한 잔차 변동성 |

일반적인 회귀분석의 제곱합 관계는 다음과 같다.

`SST = SSR + SSE`

- SST: 실제 관측값이 전체 평균으로부터 얼마나 떨어져 있는지 측정한다.
- SSR: 회귀모델의 예측값이 전체 평균으로부터 얼마나 떨어져 있는지 측정한다.
- SSE: 실제 관측값과 모델 예측값 사이의 차이를 측정한다.

※ 회귀분석에서 절편이 포함된 일반적인 최소제곱 회귀모델을 기준으로 설명한 관계이다. 문헌에 따라 SSR을 잔차 제곱합으로 사용하는 경우도 있으므로 기호의 정의를 확인해야 한다.

### 1-3. 베이스라인 모델(Baseline Model)

베이스라인 모델은 복잡한 모델을 개발하기 전에 성능을 비교하기 위한 기본 모델이다.

예를 들어 회귀분석에서는 전체 데이터의 평균값을 예측하는 단순 모델을 베이스라인으로 사용할 수 있다.

이후 개발한 회귀모델이 베이스라인 모델보다 얼마나 개선되었는지 확인한다.

**핵심:** 모델의 성능은 단순히 수치가 높거나 낮은지만 보는 것이 아니라 적절한 기준 모델과 비교해야 한다.

## 2. 상관관계(Correlation)와 회귀분석(Regression)

### 2-1. 상관관계

상관관계는 두 변수 사이에 어떤 관계가 있는지 나타내는 통계적 지표이다.

상관계수는 일반적으로 -1에서 1 사이의 값을 가진다.

| 상관계수 | 의미 |
|---|---|
| +1에 가까움 | 강한 양의 상관관계 |
| 0에 가까움 | 선형 상관관계가 약함 |
| -1에 가까움 | 강한 음의 상관관계 |

※ 상관계수 0은 두 변수 사이에 어떠한 관계도 없다는 뜻이 아니다. 비선형 관계가 존재할 수도 있다.

### 2-2. 상관관계의 종류

**양의 상관관계**

- 한 변수가 증가할 때 다른 변수도 증가하는 경향이 있는 관계
- 예: 공부 시간이 증가할수록 시험 점수가 높아지는 경향

**음의 상관관계**

- 한 변수가 증가할 때 다른 변수는 감소하는 경향이 있는 관계
- 예: 상품 가격이 상승할수록 구매량이 감소하는 경향

### 2-3. 회귀분석(Regression Analysis)

회귀분석은 하나 이상의 독립변수가 종속변수와 어떤 관계를 가지는지 수학적 모델로 분석하는 통계기법이다.

주요 목적은 다음과 같다.

1. 변수 간 관계 모델링
2. 독립변수에 따른 종속변수의 변화 분석
3. 미래 또는 새로운 데이터의 값 예측

예시:

- 독립변수: 공부 시간
- 종속변수: 시험 점수

공부 시간에 따라 시험 점수가 어떻게 달라지는지 분석하고, 공부 시간을 바탕으로 시험 점수를 예측할 수 있다.

### 2-4. 상관관계와 회귀분석의 차이

| 구분 | 상관관계 | 회귀분석 |
|---|---|---|
| 목적 | 두 변수의 관계와 방향 확인 | 변수 간 관계 모델링 및 예측 |
| 결과 | 상관계수 | 회귀계수, 예측값 등 |
| 변수 구분 | 두 변수의 역할을 구분하지 않음 | 독립변수와 종속변수를 구분 |
| 활용 | 관계의 강도와 방향 파악 | 영향 관계 분석 및 예측 |

상관관계보다 회귀분석이 항상 우수하거나 더 정확하다는 의미는 아니다.

두 기법은 목적이 다르며, 회귀분석은 상관관계보다 더 구체적인 수학적 모델을 구성할 수 있다는 차이가 있다.

## 3. 상관성(Correlation)과 인과성(Causation)

### 3-1. 상관성

두 변수 사이에 함께 변화하는 관계가 존재하는 것을 의미한다.

예시:
- 음악을 듣는 사람과 집중력 사이에 관계가 관찰됨.
- 운동 시간이 길수록 건강 관련 지표가 좋아지는 경향이 나타남.

### 3-2. 인과성

한 변수의 변화가 다른 변수의 변화를 발생시키는 원인과 결과의 관계를 의미한다.

예시:

`음악 감상 → 집중력 변화`

음악 감상이 집중력에 영향을 주는지 확인하려면 다른 조건을 통제하고 실험하는 등의 방법이 필요하다.

### 3-3. 상관관계와 인과관계의 차이

| 구분 | 상관관계 | 인과관계 |
|---|---|---|
| 의미 | 두 변수가 함께 변화하는 관계 | 한 변수의 변화가 다른 변수에 영향을 주는 관계 |
| 방향 | 변수 간 연관성을 나타냄 | 원인과 결과의 방향이 존재 |
| 증명 | 상관계수 등으로 측정 가능 | 실험 및 인과추론 등의 추가적인 근거 필요 |

**중요한 원칙**

상관관계가 존재한다고 해서 반드시 인과관계가 성립하는 것은 아니다.

예를 들어 음악을 듣는 사람의 집중력이 높게 나타났다고 하더라도 음악이 집중력을 높였다고 단정할 수는 없다.

집중력이 높은 사람이 음악을 더 자주 듣는 것일 수도 있고, 수면이나 학습 환경 등 제3의 변수가 영향을 주었을 수도 있다.

## 4. 트레이드오프(Trade-off)

트레이드오프란 하나의 요소를 개선하면 다른 요소에서 손해나 제약이 발생할 수 있는 관계를 의미한다.

즉, 여러 목표를 동시에 최대로 달성하기 어려운 상황에서 적절한 균형점을 선택하는 것이다.

예시:

| 상황 | 트레이드오프 |
|---|---|
| 모델 개발 | 정확도와 모델 복잡도 |
| 데이터 분석 | 분석 속도와 분석 정밀도 |
| 서비스 운영 | 사용자 편의성과 보안 수준 |
| 머신러닝 | 편향(Bias)과 분산(Variance) |

모든 조건을 완벽하게 만족시키기보다는 목적과 상황에 맞는 최적의 균형을 찾아야 한다.

## 5. 통계적 오류와 평균의 함정

### 5-1. 앤스콤 콰르텟(Anscombe's Quartet)

앤스콤 콰르텟은 1973년 영국의 통계학자 프랜시스 앤스콤(Francis Anscombe)이 제시한 데이터 집합이다.

이 사례는 기술통계량이 비슷하거나 동일하더라도 실제 데이터의 분포와 관계는 크게 다를 수 있다는 사실을 보여준다.

**핵심 내용**

- 평균이 같을 수 있다.
- 분산이 같을 수 있다.
- 상관계수가 같을 수 있다.
- 회귀선이 같을 수 있다.
- 그러나 실제 데이터의 분포와 관계는 다를 수 있다.

따라서 평균이나 상관계수만 확인해서는 안 되며, 반드시 데이터 시각화를 통해 분포와 이상치를 확인해야 한다.

### 5-2. 심슨의 역설(Simpson's Paradox)

전체 데이터를 합쳐서 분석했을 때의 결과가 개별 그룹으로 나누어 분석했을 때의 결과와 반대로 나타나는 통계적 현상이다.

예를 들어 대학의 전체 합격률을 비교했을 때 A대학이 B대학보다 낮더라도, 학과별 합격률을 비교하면 A대학이 모든 학과에서 더 높게 나타날 수 있다.

이는 전체 데이터와 그룹별 데이터의 구성 비율이 다르기 때문에 발생할 수 있다.

**핵심:** 전체 평균이나 비율만으로 판단하지 말고 그룹별 데이터도 함께 확인해야 한다.

### 5-3. 기초 통계값

| 통계값 | 확인할 내용 |
|---|---|
| 평균 | 데이터의 산술적 중심 |
| 중앙값 | 데이터를 순서대로 정렬했을 때 가운데 값 |
| 분산 | 평균을 기준으로 한 데이터의 퍼짐 정도 |
| 표준편차 | 데이터가 평균에서 얼마나 떨어져 있는지 나타내는 값 |
| 분포 | 데이터가 어떤 형태로 퍼져 있는지 확인 |
| 빈도 | 특정 값이나 범주가 나타난 횟수 |
| 비율 | 전체에서 특정 범주가 차지하는 비중 |
| 표본 크기 | 분석에 사용한 관측치의 수 |
| 불확실성 | 추정 결과나 분석 결과의 불확실한 정도 |

기초 통계값을 종합적으로 확인해야 데이터의 특성을 올바르게 이해할 수 있다.

### 5-4. 클래스 분포(Class Distribution)

분류 모델에서 각 클래스가 차지하는 데이터의 비율을 의미한다.

예를 들어 클래스 비율이 3:7이라면 전체 데이터 중 한 클래스가 30%, 다른 클래스가 70%를 차지한다는 의미이다.

클래스 비율이 3:7이라고 해서 무조건 분석을 진행해도 된다는 의미는 아니다.

다음 사항을 확인해야 한다.

- 클래스 불균형이 모델 성능에 영향을 주는가?
- 소수 클래스의 예측이 중요한 문제인가?
- 정확도 외에 정밀도(Precision), 재현율(Recall), F1-score 등을 확인해야 하는가?
- 필요하다면 가중치 조정이나 리샘플링이 필요한가?

## 6. 측정수준(Measurement Scale)

측정수준은 데이터를 어떤 기준으로 측정하고 분류하는지 나타내는 개념이다.

대표적으로 명목척도, 서열척도, 등간척도, 비율척도 네 가지로 구분한다.

### 6-1. 명목척도(Nominal Scale)

어떤 범주에 속하는지 구분하는 척도이다.

예시:
- 혈액형
- 거주 지역
- 상품 종류
- 성별

특징:
- 값 사이에 순서가 없다.
- 숫자로 표현하더라도 크기나 순서를 의미하지 않는다.
- 범주별 빈도와 비율을 구할 수 있다.

### 6-2. 서열척도(Ordinal Scale)

데이터 사이의 순서나 높고 낮음을 구분하는 척도이다.

예시:
- 만족도 등급
- 학점 등급
- 서비스 평가 순위

특징:
- 값 사이에 순서가 존재한다.
- 단계 사이의 간격이 동일하다고 보장할 수 없다.
- 순위 비교는 가능하지만 차이의 크기를 정확하게 비교하기 어렵다.

### 6-3. 등간척도(Interval Scale)

값 사이의 간격이 일정한 척도이다.

예시:
- 섭씨온도(℃)
- 화씨온도(℉)
- 연도

특징:
- 값 사이의 차이를 비교할 수 있다.
- 절대적인 0이 존재하지 않는다.
- 값의 배수 비교는 적절하지 않다.

예를 들어 20℃는 10℃의 두 배로 따뜻하다고 표현할 수 없다.

### 6-4. 비율척도(Ratio Scale)

절대적인 0이 존재하며 값 사이의 차이와 비율을 모두 비교할 수 있는 척도이다.

예시:
- 몸무게
- 키
- 거리
- 시간
- 매출액

특징:
- 값 사이의 간격이 일정하다.
- 0은 측정하려는 양이 없음을 의미한다.
- 덧셈, 뺄셈, 곱셈, 나눗셈을 통한 비교가 가능하다.

예를 들어 몸무게 60kg은 30kg의 두 배라고 표현할 수 있다.

### 6-5. 측정수준 비교

| 측정수준 | 핵심 질문 | 순서 | 간격 | 절대적 0 |
|---|---|---|---|---|
| 명목척도 | 어떤 범주인가? | 없음 | 없음 | 없음 |
| 서열척도 | 어느 것이 더 높은가? | 있음 | 일정하지 않음 | 없음 |
| 등간척도 | 얼마나 차이가 나는가? | 있음 | 일정함 | 없음 |
| 비율척도 | 몇 배 차이가 나는가? | 있음 | 일정함 | 있음 |

## 7. 데이터 분석을 위한 문제 정의

### 7-1. 문제 정의란?

데이터를 근거로 어떤 문제를 해결하고 무엇을 결정할 것인지 명확하게 설정하는 과정이다.

단순히 데이터를 분석하는 것이 아니라 분석 결과를 통해 어떤 의사결정을 내릴 것인지 정하는 것이 중요하다.

### 7-2. 문제 정의의 구성요소

| 구분 | 핵심 질문 | 목적 |
|---|---|---|
| 문제 정의 | 어떤 상황을 개선하려는가? | 분석 가능한 문제 설정 |
| 서비스 지표 | 무엇을 어떻게 측정할 것인가? | 명확한 측정 기준 설정 |
| 의사결정 | 어떤 행동을 하고 어떻게 검증할 것인가? | 실행계획과 검증 기준 설정 |

### 7-3. 문제 정의를 위해 고려해야 할 내용

1. 관찰한 상황: 현재 어떤 문제가 발생하고 있는가?
2. 확인할 차이: 어떤 데이터에서 차이가 발생하는가?
3. 영향: 해당 문제가 어떤 영향을 미치는가?
4. 분석 질문: 데이터를 통해 무엇을 확인할 것인가?
5. 연결할 결정: 분석 결과를 바탕으로 어떤 행동을 할 것인가?

### 7-4. 지표(Index / Metric)

지표란 어떤 대상이나 현상을 계량적·수치적으로 표현한 것이다.

예시:
- 주가지수
- 매출액
- 방문자 수
- 구매 전환율
- 재방문율

※ 실무에서 개별 측정값은 Metric, 여러 측정값을 조합한 종합 지표는 Index라고 구분하는 경우도 있다.

### 7-5. 사용자 행동에 맞춘 서비스 지표

사용자가 서비스를 이용하는 과정에 따라 적절한 지표를 설정할 수 있다.

| 사용자 단계 | 확인할 지표 예시 |
|---|---|
| 방문 | 방문자 수, 페이지 조회 수 |
| 가입 및 첫 사용 | 가입자 수, 가입 전환율, 첫 사용률 |
| 반복 사용 | 사용 빈도, 활성 사용자 수 |
| 구매 | 구매자 수, 구매 전환율, 평균 구매 금액 |
| 재방문 | 재방문율, 재구매율, 이탈률 |

**핵심:** 서비스의 목적과 사용자 행동에 맞는 지표를 선택해야 한다.

## 8. 데이터 분석 시대의 핵심 역량

바이브 코딩과 AI의 발전으로 코드를 작성하거나 데이터를 처리하는 작업이 이전보다 쉬워지고 있다.

그러나 분석 결과를 올바르게 이해하고 판단하는 능력은 여전히 중요하다.

### 8-1. 바이브 코딩(Vibe Coding)

개발자가 직접 코드를 작성하는 대신 일상적인 언어로 아이디어와 요구사항을 설명하면 AI가 실행 가능한 코드를 생성하거나 수정해 주는 프로그래밍 방식이다.

### 8-2. 핵심 역량

1. 문제와 질문 구체화
2. 데이터와 맥락 확인
3. 결과와 근거 검증
4. 한계를 고려한 활용

AI가 코드를 작성하더라도 결과가 정확한지, 데이터가 적절한지, 분석 결과가 실제 문제를 해결하는지 판단하는 능력이 중요하다.

## 9. AI 리터러시(AI Literacy)

### 9-1. 인공지능(AI), 머신러닝, 딥러닝

인공지능, 머신러닝, 딥러닝은 서로 포함 관계를 가진 개념이다.

```text
인공지능(Artificial Intelligence)
│
└── 머신러닝(Machine Learning)
    │
    └── 딥러닝(Deep Learning)
```

| 구분 | 정의 |
|---|---|
| 인공지능(AI) | 인간의 지적 능력을 컴퓨터로 구현하는 기술 |
| 머신러닝(ML) | 데이터에서 패턴과 규칙을 학습하여 결과를 도출하는 기술 |
| 딥러닝(DL) | 여러 층의 인공신경망을 이용하여 데이터를 학습하는 머신러닝의 한 분야 |

### 9-2. 기계학습 알고리즘(Machine Learning)

기계학습은 학습 데이터의 목표변수(Target Variable) 유무에 따라 크게 지도학습과 비지도학습으로 구분한다.

#### 지도학습(Supervised Learning)

정답이 포함된 데이터를 학습하여 새로운 데이터의 결과를 예측하는 방식이다.

- 목표변수가 존재한다.
- 입력 데이터와 정답 데이터를 함께 학습한다.

**① 분류(Classification)**

미리 정해진 범주 중 어디에 속하는지 예측한다.

예시:
- 스팸 메일 / 정상 메일
- 합격 / 불합격
- 고양이 / 강아지

**② 회귀(Regression)**

연속적인 수치나 양을 예측한다.

예시:
- 주택 가격 예측
- 매출액 예측
- 기온 예측

#### 비지도학습(Unsupervised Learning)

정답이 없는 데이터를 이용하여 데이터 내부의 구조나 패턴을 찾는 방식이다.

- 목표변수가 존재하지 않는다.
- 데이터의 특성과 관계를 탐색한다.

주요 기법:

1. 차원축소(Dimensionality Reduction)
2. 군집화(Clustering)
3. 연관규칙 분석(Association Rule Mining)

※ 실무에서 지도학습과 비지도학습 중 어느 한쪽을 항상 더 많이 사용한다고 단정할 수는 없다. 해결하려는 문제와 데이터의 특성에 따라 활용 방식이 달라진다.

### 9-3. 베이스라인 모델(Baseline Model)의 기준

베이스라인 모델은 복잡한 모델을 만들기 전에 비교 기준으로 설정하는 단순한 모델이다.

분류 문제에서 무작위로 클래스를 예측한다고 가정하면 클래스 개수에 따라 균등한 확률을 계산할 수 있다.

| 클래스 개수 | 균등 무작위 예측의 기대 정확도 |
|---|---:|
| 2개 | 50% |
| 3개 | 약 33.3% |
| 4개 | 25% |
| 5개 | 20% |
| 10개 | 10% |

예를 들어 0~9까지 총 10개의 클래스를 분류하는 문제에서 균등 무작위 예측의 기대 정확도는 10%이다.

다만 이것이 모든 분류 문제의 베이스라인 기준이 되는 것은 아니다.

**실무에서 사용하는 베이스라인의 예시**

- 다수 클래스 예측: 가장 많은 비율을 차지하는 클래스를 항상 예측
- 무작위 예측: 정해진 확률에 따라 클래스를 예측
- 단순 규칙 기반 모델: 간단한 규칙으로 결과 예측

예를 들어 클래스 비율이 3:7이라면 다수 클래스만 예측하는 모델의 정확도는 70%가 된다.

따라서 균등 무작위 예측의 50% 또는 10%만 기준으로 삼으면 실제 성능을 잘못 판단할 수 있다.

**핵심:** 베이스라인은 데이터의 클래스 분포, 문제의 목적, 평가 지표를 고려하여 설정해야 한다.

### 9-4. 회귀모델과 분류모델

| 구분 | 회귀모델 | 분류모델 |
|---|---|---|
| 예측 대상 | 수치 및 양 | 미리 정해진 범주 |
| 예시 | 주택 가격 | 주택 가격대 등급 |
| 결과 | 3억 5천만 원 | 고가 / 중가 / 저가 |
| 주요 평가 지표 | MAE, MSE, RMSE, R² | Accuracy, Precision, Recall, F1-score |

### 9-5. 딥러닝(Deep Learning)

딥러닝은 여러 개의 은닉층(Hidden Layer)을 가진 인공신경망을 사용하여 복잡한 데이터의 특징과 패턴을 학습하는 머신러닝의 하위 분야이다.

특징:
- 여러 층의 인공신경망을 사용한다.
- 데이터에서 복잡한 특징을 학습할 수 있다.
- 이미지, 음성, 텍스트 등의 데이터 처리에 활용된다.

### 9-6. 인공지능 모델 학습(Model Training)

인공지능 모델 학습이란 데이터를 이용하여 모델의 예측값과 실제 정답 사이의 차이를 줄이는 방향으로 최적의 모델 파라미터를 찾아가는 과정이다.

일반적인 학습 과정:

1. 학습 데이터 입력
2. 모델의 예측값 생성
3. 실제 정답과 예측값 비교
4. 손실함수(Loss Function) 계산
5. 최적화 알고리즘을 통한 파라미터 업데이트
6. 반복 학습

### 9-7. LLM(Large Language Model)

LLM은 대규모 데이터로 학습한 자연어 처리 기반의 딥러닝 모델이다.

자연어를 이해하고 문맥에 맞는 텍스트를 생성하는 데 활용된다.

**Large**

- 대규모 학습 데이터
- 많은 수의 모델 파라미터
- 대규모 연산 자원 활용

**Language Model**

- 언어의 패턴과 문맥을 학습
- 주어진 문맥을 바탕으로 다음 토큰을 예측하는 방식 등을 사용

**주요 특징**

| 구분 | 내용 |
|---|---|
| 기반 구조 | 대부분 Transformer 기반 |
| 학습 방식 | 대규모 텍스트 데이터를 이용한 사전학습 등 |
| 예측 방식 | 다음 토큰 예측 등 |
| 주요 기능 | 텍스트 생성, 요약, 번역, 질의응답, 코드 생성, 분류 |

※ 모든 LLM이 동일한 방식으로 작동하는 것은 아니다. 일반적인 자기회귀 언어모델은 다음 토큰을 예측하며, 일부 모델은 마스킹된 토큰 복원 등 다른 학습 방식을 사용한다.
